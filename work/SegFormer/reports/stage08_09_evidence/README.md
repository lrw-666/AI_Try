1. `overfit_002` 评价的 8 个 image ID 全部属于 train，但旧评分函数把每条 `split` 硬编码成 `val`。**数值属于训练子集**；当前代码和新复验报告已更正元数据，归档原件保留错误，避免静默改写历史。
