# 阶段 07 验收前历史记录

`loss_metrics_check.json` 是验收前的原始 `/1` 报告，保留用于追溯，不能证明当前代码通过验收，也不是模型性能结果。

其中旧的“12 像素差异”已撤回。旧算法相加的是全局 TP/FP/FN 净变化的绝对值：不同图片的变化可能抵消，同一变化还可能同时进入 TP 和 FN。该值不等于两张预测掩码逐像素 XOR 的数量；原报告没有保存足够信息，不能据此恢复真实像素差。

当前证据入口为上一级的 `loss_metrics_check.json` 与 `stage07-acceptance.json`。历史报告中的随机解码头指标均不得引用为基线性能。
