# machine. requirements-runtime.txt pins the COMPLETE runtime stack. This file
# only installs the two CUDA packages, not the full SegFormer environment:
#
#   Invoke-SegPip install --no-user -r requirements-runtime.txt --index-url https://pypi.org/simple
