## 摘要

无监督学习已经成为人工智能系统不可或缺的组成部分。它所产生的表征，例如基础模型中的表征，对大量下游应用至关重要。因此，需要仔细检查无监督模型，既要确保它们能在现有数据上给出准确预测，也要确保这些准确预测并非来自聪明汉斯（CH）效应。本文使用专门开发的可解释人工智能技术，对流行的图像表征学习与异常检测模型进行分析，表明 CH 效应广泛存在于无监督学习中。具体而言，通过医学与工业检测数据的应用案例，我们证明，在合理的数据集偏移或不同数据子群重新加权条件下，CH 效应会系统性地使下游模型的性能显著下降。理论分析进一步充实了这些实证发现，指出无监督学习机制中的归纳偏置是 CH 效应的主要来源。总体而言，本研究揭示了无监督学习实际应用中尚未得到充分探索的风险，并提出系统性缓解 CH 效应、提高无监督学习鲁棒性的途径。

## 引言

无监督学习是近年来日益受到重视的机器学习分支[1–3]。它解决监督学习的一些根本限制，例如缺少数据标签，或获取标签的成本过高。无监督学习在对未知事物建模方面已经取得成功，例如发现新的癌症亚型[4,5]，或从大型历史语料中提取新的认识[6]。此外，无监督学习不依赖任务特定标签，因此适合作为核心人工智能基础设施：无监督异常检测为输入数据的各种质量或完整性检查提供基础[7–10]。无监督学习也是“基础模型”背后的关键技术[1,11–15]；基础模型提取的表征，可以支撑分类、回归、“生成式人工智能”等各种下游模型。

无监督学习模型的日益普及，使得仔细检查模型如何得出预测成为迫切需求。只有这样，才能确保模型处理和表征输入数据时可能存在的缺陷，不会传播给建立在它们之上的众多下游监督模型。

本文对多个流行的图像无监督机器学习模型进行研究，表明无监督学习模型普遍受到聪明汉斯（CH）效应的影响[16]。具体来说，我们发现，无监督模型产生的表征常常能够正确地把样本判断为相似或异常，但这些判断在很大程度上受到数据质量伪影的支撑。这种有缺陷的预测策略无法通过交叉验证等常规评测发现，却可能在很久以后的“下游”应用中表现为意外错误，例如部署后输入数据发生细微变化时（图 1）。虽然监督学习中的 CH 效应已经得到较充分研究[16–22]，无监督学习中却缺少类似研究；考虑到无监督模型支撑大量下游应用，这一点令人担忧。

例如，基于图像的工业检测往往依赖无监督异常检测[9,10]。我们发现，CH 决策策略会系统性漏掉多种制造缺陷，从而可能造成高昂成本。再如，医学领域提倡使用图像基础模型，为各种专门诊断任务提供鲁棒特征，但这些无监督基础模型也可能将 CH 效应引入许多任务，带来大范围误诊风险。这些场景见图 1，说明了无监督 CH 效应的实际影响：与监督学习中的对应问题不同，它可能影响的不是某一特定任务，而是所有下游任务。

为了发现并理解无监督 CH 效应，我们提出使用可解释人工智能[23–27]，具体采用基于逐层相关性传播（LRP）解释框架的技术[28–30]。这些技术使我们无需先定义具体下游任务，就能大规模识别无监督机器学习模型使用或误用的输入特征。我们使用 LRP 的扩展方法 BiLRP[31]，揭示哪些输入模式共同造成表征空间中的相似性；还将 LRP 与“虚拟层”[32,33]结合，揭示哪些像素和频率成分共同支撑预测的异常。

此外，基于可解释人工智能的分析使我们能够更形式化地定位无监督 CH 效应的成因。尤其是，其主要原因往往不是数据本身，而是无监督学习机制：即使有海量数据点可用，该机制也可能阻碍真正支撑任务的特征进入模型。我们的发现为开发有针对性的 CH 缓解策略、增强模型鲁棒性提供了新方向。

总体而言，本研究揭示了无监督学习中 CH 效应的存在、突出程度及独特性，呼吁对这一现代人工智能系统的关键组成部分进行更严格检查。

## 结果

CH 效应可定义为模型的一种性质：模型依赖某些特征，这些特征由于与真实信号存在虚假相关性，在特定条件下具有预测能力，但在新数据上不再如此，从而导致性能显著下降。关于形式化描述，以及它与捷径学习[17]、人类—人工智能对齐[34,35]等相关概念的区别，另见补充说明 D。本文以可解释人工智能为主要分析工具，对表征学习和异常检测这两类代表性无监督模型开展实验，展示 CH 效应的广泛存在、不良后果及可能的缓解策略。

### 表征学习中的 CH 效应

首先，我们研究使用近期医学基础模型解决 COVID-19 检测任务时的 CH 效应。为了模拟疫情初期数据稀缺的情况，与文献[19]类似，我们把一个大型、成熟的非 COVID-19 数据集与一个较新、较小的 COVID-19 数据集合并。具体而言，合并美国国立卫生研究院 NIH CXR8 数据集[36]中于 1992–2015 年采集的 2,597 个样本，以及托管在 GitHub 上的“COVID-19 图像数据集合”[37]中的 535 个样本；后者包含来自多个来源的 COVID-19 样本。下文分别称它们为 NIH 子集和 GitHub 子集。

考虑到 COVID-19 样本极少，并希望避免过拟合，我们进一步选择使用无监督基础模型提供的表征[15,38–40]。具体来说，将数据输入预训练 PubMedCLIP 模型[39]，该模型从大量 X 射线扫描中以无监督方式建立表征。我们在 PubMedCLIP 上训练下游分类器，区分 COVID-19 与非 COVID-19 样本。它在测试集上达到 87.5% 的类别平衡准确率（表 1）。然而，进一步分析这一分数的组成，会发现 NIH 与 GitHub 子群存在明显差异：所有 NIH 样本都被正确分类，GitHub 样本的类别平衡准确率却降至 81.7%，更突出的是，其假阳性率（FPR）达到 51%，如表 1 所示。GitHub 数据集具有更高的样本异质性，更接近真实条件，因此这一较高的错误估计更加现实。尤其是，51% 的高 FPR 使模型无法实际用于住院医疗场景；在这种场景中，模型应当可靠、低风险地辅助选择适当治疗。我们强调，如果没有仔细关注或了解数据来源，只依赖总体准确率，就很容易忽略这一模型缺陷。

为了主动检测这种异质、缺乏鲁棒性的预测行为，我们提出使用可解释人工智能。具体而言，为检查缺陷是否源于无监督 PubMedCLIP 组件，我们使用 BiLRP 解释技术[31]。BiLRP 直接作用于表征空间中的相似性，无需定义特定下游任务；其示意见图 2，数学形式见“方法”。图 3 左侧给出了两组 COVID-19 阳性样本对的 BiLRP 结果，显示模型给出的相似性来自两张图像中都出现的文本式注释。由此，我们能够把性能异质性归因于 CH 效应，并进一步指出下游应用的广泛风险，更多分析见补充说明 A。与前述分组准确率分析不同，基于 BiLRP 的可解释分析既不需要 GitHub 或 NIH 等来源元数据，也不关注带有专属标签的某个特定下游任务。

为了检验表征学习是否在上述案例之外也普遍倾向于形成 CH 策略，我们下载了三个通用基础模型：原始 CLIP[13]、SimCLR[12,41] 和 Barlow Twins[42]。CLIP 包含图像编码器和文本编码器，通过最小化对比损失，在表征空间中对齐图像及其配对文本。SimCLR 和 Barlow Twins 则通过随机缩放裁剪、颜色增强生成输入图像的增强视图，并最大化两种视图在表征空间中的相似性。下游任务是利用线性 softmax 分类器，对 ImageNet[43]中共享 WordNet ID“truck”的 8 个类别，以及共享 WordNet ID“fish”的 16 个类别分类，详见方法。各模型在这两个任务上的测试准确率列于表 1 的“原始”列。卡车分类中，CLIP 最佳，准确率为 84.7%；鱼类分类中，CLIP 和监督模型最佳，分别为 85.4% 和 85.9%。

我们使用 BiLRP 检查这些无监督模型的表征。图 3 中间显示，与 PubMedCLIP 类似，CLIP 的相似性也依赖文本：两张垃圾车图像左下角的文本标志被用来支撑相似性，提示存在 CH 效应，监督学习中的类似发现见文献[20]。SimCLR 和 Barlow Twins 忽略文本，而依赖实际的垃圾车。在鱼类分类任务中（图 3 右侧），所有无监督模型都相对于鱼类特征放大了人物特征，再次提示 CH 效应。

为了确定 BiLRP 识别出的标志检测和人物检测策略确实具有 CH 性质，我们在实际运行中可能更加常见的特定数据子群上测试模型，结果见表 1。从原始数据转到部分子集时，性能出现系统性下降。例如，在每张卡车图像上都插入标志，从而打破标志与卡车类别间的虚假相关性后，CLIP 准确率从 84.7% 降至 80.3%，见表 1“标志”列。对通常难以与垃圾车区分的拖车等单独类别，性能下降更明显，见补充说明 B。鱼类任务中，只保留含人物的图像并进行类别重新平衡后，SimCLR 和 Barlow Twins 的准确率分别从 81.4%、83.2% 降至 74.8%、75.8%。令人意外的是，CLIP 对鱼的关注不足并没有造成类似性能下降，因此，究竟是什么策略使 CLIP 能在这些数据上良好泛化，仍是开放问题。补充说明 B 使用混淆矩阵，详细分析了各模型、各分类任务的预测错误结构。

为了更好评估无监督学习中 CH 效应的风险，需要思考其背后更抽象的成因。BiLRP 揭示出：即使模型都在类似的大型数据集上训练，策略仍有异质性；这提示无监督学习机制比数据本身更能决定数据表征策略。对于 SimCLR 和 Barlow Twins，图像中心人物的系统性放大可归因于随机裁剪匹配目标，因为中心特征在随机裁剪视图之间携带最多互信息；关于这类模型中特征放大／抑制效应的更多研究，见文献[44–47]。对于 CLIP 和 PubMedCLIP，文本标志、人脸或其他身份识别特征的系统性放大，则可归因于图像—文本匹配目标：这一目标倾向于放大两种模态之间具有互信息的任何特征。

总体而言，CLIP、SimCLR、Barlow Twins 等模型中的匹配任务，直观上旨在向表征引入有益先验和不变性，却可能在某些数据子集上造成不同特征表达的严重失衡。这种失衡容易引起 CH 效应，并进一步损害下游任务准确率。

### 异常检测中的 CH 效应

我们把 CH 效应研究扩展到无监督学习的另一领域——异常检测，采用基于流行 MVTec-AD 数据集[9]的工业检测案例。数据集有 15 个产品类别，每类都有无制造缺陷图像组成的训练集，以及包含有缺陷、无缺陷图像的测试集。制造缺陷稀少且形式各异，因此该问题通常采用无监督异常检测处理[2,9]。这类模型把每个样本映射为异常分数，然后可建立基于阈值的下游模型，区分有无制造缺陷的样本。无监督异常检测已受到广泛关注，PatchCore[48]、EfficientAD[49]等基于深度神经网络的复杂方法，在检测多种工业缺陷方面表现优异。

有些出乎意料的是，像素空间距离这种更简单的方法，在特定任务上也有竞争力[2]。我们研究其中一种方法，并称之为 D2Neighbors：根据样本与训练数据邻居的距离预测异常。具体地，新样本 x 的异常分数为

\[
f(x)=\operatorname{softmin}_{j}\{\|x-u_j\|^2\},
\]

其中 \((u_j)_{j=1}^{N}\) 是可用的正常样本集合，模型和预处理详见方法。这一模型属于更广泛的基于距离的模型类别[50–52]，并与核密度估计[53,54]、单类支持向量机[55]相关。使用 D2Neighbors，可以构建下游模型，在 MVTec 的瓶子、胶囊、药片、牙刷、木材五个类别上，以超过 0.9 的 F1 分数识别工业缺陷。

为理解这些出人意料的高 F1 分数所对应的预测策略，我们采用可解释人工智能：使用针对异常检测扩展的 LRP[30,56]，并进一步引入“虚拟层”[32,33]。虚拟层技术（图 4）将输入映射到抽象域再映射回来，保持预测函数不变，却提供一个可用于解释预测的新表征。我们用离散余弦变换 DCT[57]及其逆变换构造这种层，DCT 基见图 4 右下角，从而能够同时从像素和频率两个角度解释预测。

图 4 展示了两个木材样本的分析结果，其他类别见补充说明 C。像素级解释显示，D2Neighbors 的异常预测主要由实际包含工业缺陷的像素支撑。距离函数中的平方差 \(\|\Delta\|^2=\sum_i\Delta_i^2\) 促使模型产生稀疏的逐像素响应，有效排除新样本与训练样本没有差异的图像区域。然而，像素解释中仍有不可忽略的异常预测贡献来自无关背景。联合像素—频率解释澄清了这些尚未解释的贡献：它们主要来自模型决策策略中的高频部分，见图 4b、c。

LRP 分析发现 D2Neighbors 对这些无关高频特征高度暴露，因此我们怀疑这里同样存在 CH 效应。我们把图像缩放算法从 OpenCV 最近邻缩放改成更复杂、包含抗混叠的缩放方法，模拟部署后一个看似无害的数据预处理扰动。抗混叠通过削减高频来消除缩放伪影；实际中，这种变化可能来自软件更新。已有研究表明，缩放技术有时会显著影响图像质量与图像生成评估指标[58]，但它对一般机器学习模型，特别是无监督模型的影响，尚缺乏研究。D2Neighbors 在更换缩放算法前后的性能见表 2 的“原始”和“部署后”列，其 F1 分数下降近 10 个百分点。

这一性能下降，加上 LRP 揭示的高频依赖，暴露了模型的 CH 性质：缩放中加入抗混叠后，D2Neighbors 用来支撑预测的高频从数据中消失，各样本异常分数显著下降，最终导致性能下降。数据质量实际改善了，部署后性能反而下降，尤其令人意外。进一步分析可见，假阴性率（FNR）从 4% 大幅升至 23%（表 2），这可由部署后缺少支撑异常的高频解释。在工业检测中，FNR 上升可能造成严重后果：大量缺陷样本可能被漏检，并继续进入生产链，造成后续生产环节资源浪费和高昂召回成本。

与表征学习类似，需要追问 CH 效应的成因。我们将 D2Neighbors 的 CH 策略追溯到其所依赖的距离函数。与监督学习中常用的线性层不同，距离本身无法内在地建立对输入空间特定方向的不变性，使模型暴露于大量无关数据扰动。尽管容易过度暴露，距离函数——普通欧氏距离及其 ℓp 变体——仍是许多流行无监督异常模型的组成部分，主要优势是不需要有代表性的异常样本作为对照，就能建立决策边界。更先进的 PatchCore[48]也使用距离函数，只是建立在更抽象的视觉特征上，详见方法。表 2 显示，它部署后的性能同样显著下降，提示受到类似 CH 效应影响。总体而言，分析指出了一项挑战：异常模型既要足够通用，不漏掉未预期异常，又不能过度暴露，以免增加 CH 风险。

### 缓解无监督学习中的 CH 效应

利用上述可解释分析，我们希望构建在不同数据子群和部署后条件下都更加鲁棒的模型。与此前的 CH 去除技术[20,21]不同，我们针对无监督模型进行操作，而不是针对下游任务。因此，有可能在不改变下游学习机制——训练监督分类器或调整检测阈值——的情况下，实现广泛的鲁棒性提升。

首先，针对可解释分析发现错误依赖文本标志的 CLIP，我们移除在有标志和无标志图像子群之间响应差异最大的 CLIP 激活，细节见方法。我们还在异常检测中实验一种 CH 缓解方法：在模型输入处插入模糊层，裁除模型错误使用的高频，细节见方法。两种情况下，缓解技术都改善了鲁棒性，在很大程度上逆转了模拟部署后条件下的性能下降，见表 1、2 的“CH 缓解”行。这些实质上修改了模型结构的实验，再次强调学习机制在允许或防止 CH 效应方面的主要作用。

## 讨论

无监督学习是重要的机器学习类别，越来越多地用于核心人工智能基础设施，支撑分类、回归和生成式人工智能等多种下游任务。迄今许多研究关注提升无监督算法性能，例如最大化下游分类准确率。这些评估往往很少关心模型获得高性能的确切策略，尤其很少检查其是否依赖 CH 策略。

通过 BiLRP、频域 LRP 等先进可解释技术，我们展示了 CH 策略广泛存在于无监督学习中。它们可以表现为多种形式：基于无监督表征中被错误放大的文本等特征作出正确预测，或依赖异常模型过度暴露的高频特征。部署后数据分布变化时，这些有缺陷的策略不再有效。两个案例表明，这可能造成严重实际后果，如大范围患者误诊，或系统性漏检制造缺陷。同一个有缺陷的无监督表征，还可能在它支撑的许多下游模型中产生 CH 效应。

因此，解决 CH 效应对于可靠使用无监督学习至关重要。但与监督 CH 效应相比，问题增加了一层复杂性：应在下游模型中处理，还是直接在无监督模型部分处理？通过人类反馈[20,21,59]或响应条件变化[60–63]修订下游模型，可能维持给定任务的高准确率；但若每个下游任务都要重复这一过程，就不可持续。即使基础模型的缺陷已知，例如文献[64,65]，也可能仍须如此，因为重新建立无监督模型计算成本高，还需要大量测试。本文提出，直接在无监督模型设计中处理 CH 效应，以获得能够惠及所有现有及未来下游应用的持久鲁棒性。

不过，这需要对无监督 CH 效应的成因有更深入的形式化理解。我们发现，其成因与监督学习明显不同：它更少源于数据质量问题，更多源于无监督学习机制的设计缺陷。例如，本研究表明，无监督异常检测在结构上无法降低其对高频的暴露，因而不能复现监督学习中常见的过滤机制[66–68]，D2Neighbors 就是突出例子。特征过度暴露造成较高泛化错误风险，促使我们提出更根本的问题：“无监督学习适用的模型选择标准是什么？”表面简单的 D2Neighbors，在奥卡姆剃刀或其他经典标准下可能表现不错，但实验已经显示它明显缺乏泛化性和鲁棒性。因此，应细化这些标准，将过度暴露或特征平衡纳入额外因素。

在理解成因之后，我们实验了基于特征重新平衡或减少暴露的 CH 缓解策略，并在困难数据子群或模拟部署条件下获得性能提升。这说明分析具有可行动性，能够指导识别并修正无监督模型的故障组件。

虽然本文集中研究图像数据中的无监督 CH 效应及后果，但扩展到其他数据模态似乎很直接。LRP 等解释技术不依赖输入数据类型。近期 LRP 已扩展到循环神经网络[69]、图神经网络[70]、Transformer[71]和状态空间模型[72]，这些结构代表了大语言模型和其他结构化数据模型的先进技术。因此，未来可以将分析扩展到时间序列异常检测、大语言模型学习的表征等其他无监督实例，例如文献[73,74]。

总体而言，通过应用近期可解释技术，本文揭示了无监督 CH 效应的普遍性、多种成因、新数据上的准确率损失，以及可能的缓解途径。我们认为，无监督 CH 效应及其不受控制的风险具有普遍重要性，而可解释人工智能及其最新进展提供了有效的解决方式。

## 方法

本节首先介绍研究的无监督机器学习模型、应用的数据集，以及 CH 缓解技术，随后介绍解释预测的 LRP 方法、解释相似性的 BiLRP 扩展，以及生成联合像素—频率解释的“虚拟层”技术。

### 表征学习的机器学习模型与数据

表征学习实验使用 PubMedCLIP[39]、CLIP[13]、SimCLR[12,41]、Barlow Twins[42]。PubMedCLIP 是针对 X 射线数据的专用表征模型，以预训练 CLIP 为基础，在放射影像—图像描述配对集合 ROCO[75]上微调。实验选用 ResNet-50 架构变体，权重下载自文献[76]。CLIP 利用互联网上大量图像—文本对学习表征：图像进入图像编码器，相应文本进入文本编码器，通过对比损失最大化两个嵌入的相似性。实验同样使用 ResNet-50 变体，权重来自文献[77]。

SimCLR 对输入施加缩放裁剪、颜色扰动和高斯模糊，生成同一图像的两个不同视图，再构造正负样本对。正对是同一图像的不同视角，负对由不同图像配对形成。对比损失最大化正对表征相似性，同时最小化负对相似性。我们使用 ResNet-50 架构，权重来自 vissl 库（https://vissl.ai/）。Barlow Twins 与 SimCLR 类似，也用随机缩放裁剪和颜色增强产生视图，并最大化表征空间中的相似性，但防止表征坍塌的具体机制不同。实验仍使用 ResNet-50，权重来自文献[78]。所有表征实验还设置一个监督基线，采用同样的 ResNet-50 架构，但以纯监督方式通过反向传播训练，使用 torchvision 库的默认模型权重。

**下游分类器。** 为确定无监督模型中的 CH 效应及其在下游任务中的表现，我们在无监督表征上建立线性分类器，亦称读出器。对 COVID-19 检测等二分类任务，训练线性支持向量机，细节见补充说明 A；通过留出验证将松弛参数 C 设为 0.01。对 8 类卡车、16 类鱼的多分类任务，使用 sklearn 的逻辑回归分类器，lbfgs 求解器，L2 正则化 C＝1.0，不设偏置，最大 1,000 次迭代，采用类别平衡采样。

**数据集。** 分析和训练使用不同数据集。X 射线实验将 NIH ChestX-ray8（CXR8）[36,79]和 GitHub 托管的“COVID-19 图像数据集合”[37,80]合并。GitHub 数据含 342 张 COVID-19 阳性、193 张阴性图像。按 80:20 划分，训练集得到 272 阳性、168 阴性，测试集得到 70 阳性、25 阴性。训练集另加入从 NIH 随机选择的 2,552 张阴性图像，测试集另加入 45 张 NIH 阴性图像，使测试集类别平衡。选择时保证同一患者 ID 不同时出现在训练集和测试集。全部图像缩放并中心裁剪为 224×224 像素。

ImageNet 实验使用两个子集。卡车子集由共享 WordNet ID“truck”的 8 类组成：小型厢式车、货运厢式车、警用厢式车、消防车、垃圾车、皮卡、拖车、挂车；共有 10,259 个训练和 400 个测试样本。鱼子集由共享 WordNet ID“fish”的 16 类组成：丁鱥、蛇鲭、银鲑、鲟鱼、雀鳝、魟鱼、大白鲨、双髻鲨、虎鲨、河鲀、电鳐、金鱼、鳗鱼、海葵鱼、岩美人神仙鱼、狮子鱼；共有 20,334 个训练和 800 个测试样本。

> 译注：以上 GitHub 的 80:20 划分描述、272／168／70／25 数字，以及各类名称均按原文保留；不能据“80:20”字面自行改写实际报告的类别计数。

### 异常检测的机器学习模型与数据

本文 D2Neighbors 是基于距离的异常检测器家族的一个实例，该家族涵盖文献[2,50–52,81,82]等方法。D2Neighbors 计算异常分数

\[
o(x)=\mathbb{M}^{\gamma}_{j}\{\|x-u_j\|_{p}^{p}\},
\]

其中 x 为输入，\((u_j)_{j=1}^{N}\) 为训练数据，\(\mathbb{M}^{\gamma}\) 是由 \(f(t)=\exp(-\gamma t)\) 定义的广义 f 均值。预测异常分数可理解为到各数据点距离的软最小值，即到最近邻的距离。实验输入是 224×224 图像，像素编码到 −1 与 1 之间；原始高分辨率图像用 OpenCV 的快速最近邻插值下采样。设置 γ，使平均困惑度[83]等于各模型训练集大小的 25%。

我们还研究 PatchCore[48]异常检测模型，它使用固定预训练网络的中层图像块特征，在训练中由正常图像特征构建记忆库。测试图像的异常分数，是各测试图像块特征与其记忆库最近邻距离中的最大值。距离在图像块特征 \(\phi_k(x)\) 与不依赖位置的原型记忆库 \((u_j)_{j=1}^{N}\) 之间计算，总体异常分数为

\[
o(x)=\max_k\min_j\|\phi_k(x)-u_j\|.
\]

函数 \(\phi_k\) 是预训练 WideResNet50 在空间图像块位置 k 上，由两个连续层聚合得到的特征。连续层特征通过缩放和拼接特征图聚合。本文 F1 与原论文[48]不同，主要因为图像缩放方法不同。我们使用作者参考实现[84]开展实验。

**数据集。** 上述全部模型均在 MVTec-AD 上训练。该数据集有瓶子、电缆、胶囊、地毯、网格、榛子、皮革、金属螺母、药片、螺钉、瓷砖、牙刷、晶体管、木材、拉链 15 个工业物体或纹理类别，每类都有良品和缺陷样本。D2Neighbors 实验通过改变原始高分辨率图像缩放到 224×224 的方式，模拟部署前后不同预处理条件。首先使用 OpenCV 4.9.0[85]中的最近邻插值缩放；然后使用 Pillow 10.3.0 实现、torchvision 0.17.2[86]默认采用的双线性插值，模拟部署后条件。改进方法包含抗混叠，能够平滑缩放后图像相邻像素间的过渡。

### CH 缓解技术细节

这里详细说明减少模型对虚假特征依赖的技术。为裁除 CLIP 的文本标志响应，我们比较随机选择的有水印标志与无标志卡车图像之间的激活差异，以此衡量响应程度；随后将图像底部差异最大的前 k 个滤波器置零。正文裁除 5 个，补充信息还实验不同 k。我们检查多个层，最终选择早期层 encoder.relu3，因为与网络后部更抽象的层相比，该层的较大差异集中在少数滤波器中。

异常检测分析发现模型错误使用高频，因此我们通过在模型输入处加入低通滤波器来裁除高频：分别对红、绿、蓝通道使用 11×11 高斯滤波器进行卷积。

### 表征学习的解释

实验研究表征空间中的点积相似性

\[
y=\langle\Phi(x),\Phi(x')\rangle,
\]

其中 Φ 把输入特征映射为表征，通常是深度神经网络。为把相似性解释到输入特征层面，采用专为此扩展 LRP[26,28,29,87]的 BiLRP[31]。其概念起点是：点积为输入的双线性函数。BiLRP 将双线性函数的各项反向传播到下一层激活对，迭代直至输入。记网络某中间层神经元 k、k′ 对相似性分数的贡献为 \(R_{kk'}\)，BiLRP 用以下规则得到下一层神经元对 j、j′ 的贡献：

\[
R_{jj'}=\sum_{kk'}\frac{z_{jk}z_{j'k'}}{\sum_{jj'}z_{jk}z_{j'k'}}R_{kk'}.\tag{1}
\]

其中 \(z_{jk}\) 表示神经元 j 对神经元 k 激活的贡献。实际可以通过计算一组标准 LRP 解释——表征层每个神经元对应一个解释——再以乘法方式组合，实现等价但更高效、更容易的反向传播：

\[
\operatorname{BiLRP}(y)=\sum_k\operatorname{LRP}(\Phi_k(x))\otimes\operatorname{LRP}(\Phi_k(x')).\tag{2}
\]

若输入有 d 个特征，BiLRP 输出 d×d 的解释，通常用连接两幅输入图像特征集合的加权二部图表示。由于项数很多，像素—像素贡献聚合为图像块—图像块贡献，接近零的解释项在最终图示中省略。实验使用支持 ResNet-50 的 Zennit LRP 实现[88]，LRP 参数采用默认值。

### D2Neighbors 模型的解释

研究的 D2Neighbors 由距离层和软最小池化层组成。为处理这些层，我们采用文献[30,56]专门设计的 LRP 规则。软最小层 \(\mathbb{M}^{\gamma}_{j}\) 中的传播为

\[
R_j=\frac{f(\|x-u_j\|_p^p)}{\sum_j f(\|x-u_j\|_p^p)}o(x),\tag{3}
\]

即“最小者获得最多”的重新分配，f 与广义均值中的函数相同。每个 \(R_j\) 可解释为训练点 \(u_j\) 对 x 异常性的贡献。

为了把这些分数进一步传播到像素—频率域，我们使用“虚拟层”框架[32,33]，并适配 D2Neighbors。采用图 4 右下角的 DCT[57]作为频率基，将基元素集合记为 \((v_k)_k\)。DCT 构成正交基，因此

\[
\sum_kv_kv_k^\top=I,
\]

乘以单位矩阵可理解为先映射到频域、再映射回来。p＝2 时，D2Neighbors 中距离项化为欧氏范数平方 \(\|x-u_j\|^2\)。展开后可识别像素—像素—频率交互：

\[
\begin{aligned}
\|x-u_j\|^2
&=(x-u_j)^\top\left(\sum_kv_kv_k^\top\right)(x-u_j)\\
&=\sum_k\sum_{ii'}[x-u_j]_i[x-u_j]_{i'}[v_k]_i[v_k]_{i'}.
\end{aligned}
\]

据此构建把逐样本相关性 \(R_j\) 传播到像素—像素—频率特征的 LRP 规则：

\[
R_{ii'k}=\sum_j\frac{[x-u_j]_i[x-u_j]_{i'}[v_k]_i[v_k]_{i'}}{\epsilon+\|x-u_j\|^2}R_j.\tag{4}
\]

其中 ε 为小正数，用于处理 x 与 \(u_j\) 重合的情形。对交互像素边缘化可得到约简规则 \(R_{ik}=\sum_{i'}R_{ii'k}\)；进一步对像素求和得到 \(R_k=\sum_iR_{ik}\)，或对频率求和得到 \(R_i=\sum_kR_{ik}\)。图 4 热力图由这些约简生成。
