## 1. 当前结论

**以公开电子类图像上的有监督缺陷二值分割为主线：先建立 SegFormer-B0 独立基线，再研究冻结 DINOv3-S/16 加轻量分割头的迁移方案。根据实际失败案例，选择一项适度的适配改进。**

- 起步数据建议为 **VisA 的 PCB1，使用官方 2-class high-shot 划分**。先完成单类闭环，再考虑另一 PCB 类别验证。
- “SegFormer＋冻结 DINOv3”目前表示两种方案的研究组合，**不表示已经决定将两个编码器融合为最终模型**。
- 双编码器特征融合、预测集成或蒸馏是后续候选，需要互补证据、资源实测和对照实验；开题前不将它们列为必做。
- U-Net 保留为理解编码器、解码器和跳跃连接的补课资料；无需将训练 U-Net 作为训练 SegFormer 的前置条件。
- PatchCore → Dinomaly 的正常样本异常检测保留为需求变化时的备选，不与主线同时安排完整实验；扩散、SAM、目标检测也不额外扩为必做研究点。

## 3. 研究对象与暂定题目

推荐带去讨论的暂定题目：**《基于预训练视觉表征的 PCB 外观缺陷分割方法研究》**。

推荐理由是 PCB 与电子领域直接相关，VisA 有公开图像、像素掩码和包含异常训练图的官方协议，可以支持完整监督训练。现阶段不将某个融合模块写入题目，避免方案尚未验证就被题目锁定。

### 3.1 必须明确的对象边界

VisA PCB1—4 是包含晶体管、电容、芯片等元件的板级图像，异常既有划痕等表面变化，也有缺失、错位等结构变化。因此“PCB 外观缺陷”比“单体元器件表面瑕疵”更符合这批数据的整体范围。[VisA 官方说明](https://github.com/amazon-science/spot-diff)

导师是否接受这个对象范围尚未明确，应带样例和方案讨论。当前没有证据表明导师禁止使用缺陷标注训练，不自行增加此类审批条件。

如果导师要求严格限定单体器件，应先重新核对对象、掩码与可用的监督划分。MVTec `transistor` 的官方训练集只有正常图，不能直接挪用其测试异常做监督训练后仍声称遵循原协议。这种变化要先重定数据条件，而不是仅替换一个目录名。

## 4. 两个独立模型怎样开展

### 4.1 模型 A：SegFormer-B0 监督分割基线

```text
图像 → 预训练的层级 Transformer 编码器 → 多尺度解码头 → 两类像素预测
```

- 从公开预训练权重起步，将输出类别设为背景/正常与缺陷两类，使用图像和真实掩码训练。
- 建议先用成熟 Python 接口接入，不先从零实现注意力或维护老版本训练框架。
- 理解数据、增强、损失、反向传播、验证、保存/恢复和独立推理；记录预训练权重来源。
- SegFormer 是 2021 年的成熟 Transformer 分割基线，不作为“2026 年最新模型”宣传。单基线足以开始实验，是否足以支撑最终论文对照，要根据实际研究问题判断。

依据：[SegFormer 论文](https://arxiv.org/abs/2105.15203)、[作者代码](https://github.com/NVlabs/SegFormer)。

### 4.2 模型 B：冻结 DINOv3-S/16＋简单分割头

```text
图像 → DINOv3-S/16（参数冻结）→ patch 特征图
     → 轻量分割头（训练）→ 上采样 logits → 两类像素预测
```

- DINOv3 属于自监督视觉表征学习方法及模型家族；S/16 使用 ViT Small，约 2100 万参数，patch 大小 16，特征维度 384。家族还包括 ConvNeXt，不能把 DINOv3 与 ViT 完全等同。
- 使用官方预训练权重，骨干不更新，只训练新的分割头。原始教师—学生预训练机制不需要在你的下游实验中重做。
- 下游使用缺陷掩码训练，所以仍属于有监督分割。“自监督预训练”不意味着这套下游任务不需要标签。
- 可以先用单层 `1×1` 卷积作为线性探测，再根据实验考虑小型卷积分割头；不同头应分别命名并记录，不混为同一基线。
- 例如输入 `256×256` 时，patch 网格为 `16×16`；取出 patch tokens，排除 CLS/register tokens，再恢复空间形状。该尺寸仅用于理解/调试，不是最终输入分辨率承诺。
- 冻结需控制 `requires_grad` 和反向传播范围；`eval()` 本身不会冻结参数。分割头必须保留梯度，训练损失前不能先做 `argmax`。
- 16 倍空间步长对细小缺陷有风险；插值不会凭空恢复细节，但也不能断言小于 16 像素的缺陷必然无法检测。

官方提供冻结特征用于分割等下游任务的依据。代码公开、权重可获取但有访问条件与 DINOv3 许可；原始大规模预训练数据不能视为完整公开，因此目标是下游迁移与评估，而非完整重现基础模型预训练。[官方代码与模型说明](https://github.com/facebookresearch/dinov3)、[模型卡](https://github.com/facebookresearch/dinov3/blob/main/MODEL_CARD.md)、[S/16 权重入口](https://huggingface.co/facebook/dinov3-vits16-pretrain-lvd1689m)

### 4.3 第一轮比较要回答什么

先回答“在当前数据与算力条件下，这两套可获得的预训练方案各有什么优缺点”。记录它们的缺陷定位、误检、训练参数量、显存和推理成本。

## 5. 可以形成的研究问题与改进范围

建议总问题：**在有限缺陷标注和消费级 GPU 条件下，如何利用预训练视觉特征，兼顾 PCB 缺陷定位、正常区域误报与实现成本？**

第一轮实验后，从以下候选中只选择一个主要问题深入；选择前均为假设：

| 观察到的问题 | 可考虑的适配 | 需要的验证 |
| --- | --- | --- |
| 整图缩放后小缺陷明显丢失 | 保留分辨率、受控切块或局部细节处理 | 同模型对照，按缺陷尺度分析，计算增加的推理成本 |
| 冻结特征存在但简单头定位不足 | 轻量解码头，或选取不同层的特征 | 单层/多层或简单头/改进头消融；注意多层并不等于多空间尺度 |
| 前景稀少导致漏检或误报 | 有依据的损失/采样调整 | 固定阈值选择方法，对照缺陷指标和正常图误报 |
| 两个模型在不同样本上各有优势 | 一处轻量特征融合，或先验证输出组合 | 与两个单模型比较，证明收益来自另一表征，并报告额外开销 |

切块、损失组合、多层特征与注意力都有既有研究，不将普通拼接或替换模型直接称为首次提出。开题阶段可以描述拟探索的适配思路及验证方法，不编造已有效果。

### 5.1 融合的当前定位

融合假设来自“多尺度任务适配特征与通用预训练表征可能互补”。不能简化成“SegFormer 只看局部，DINOv3 只看全局”。

- **特征融合**：中间特征对齐后结合，通常推理需要两路编码器。
- **预测集成**：两个完整模型输出概率后组合。
- **知识蒸馏**：训练时用一个模型指导另一个，推理可以只保留学生。

它们是不同的实验设计，不混称。若只是 DINOv3 编码器加 SegFormer 风格解码头，属于更换/复用模块，不等于双编码器融合。

仅当单模型闭环后出现值得解释的互补现象，再决定是否引入融合。若一条简单方案表现更合适，可直接围绕它深化，不为模型组合本身增加复杂度。

### 6.2 划分与标签

1. 保留官方测试部分；只从官方训练部分划出验证集，按正常/异常分层并固定随机种子。异常训练样本较少，应记录验证异常图数量及结论波动。
2. 先划分原图，再裁块或增强。已知有同一实物、同源图或近重复时，应按组处理并说明协议变化。
3. 正常图构造全 0 掩码；原始异常掩码中的非零缺陷 ID 合并为 1。检查实际文件取值，不能把 255 直接当忽略标签。
4. 图像和掩码同步几何变换；掩码缩放使用最近邻插值。SegFormer 二值任务检查 `do_reduce_labels=False`，以保留背景类。
5. 保留原图尺寸和长宽比处理记录；调试可从较小输入和小 batch 开始，最终尺寸以缺陷可见性与资源实测决定。
6. 两模型使用同一份训练/验证/测试清单和同一评价实现。各自需要的官方归一化可以不同，但必须记录；输入尺度差异也应说明。

### 6.3 最小评价集合

- 主指标：缺陷类 IoU、Dice，明确按全测试集累计混淆量还是逐图平均；不以大量背景像素带来的准确率作为主结论。
- 单独检查正常图误报：至少报告正常图上的误报像素比例与样例。若报告图像级误报率，先定义从像素图得到图像判定的规则。
- 保留缺陷图召回、漏检/误检可视化；若分析小缺陷，预先定义面积分组规则。
- 记录参数量、可训练参数量、输入尺寸、有效 batch、训练时长和峰值显存；推理延迟注明硬件、预热及统计方式。
- 图像/像素 AUROC、PR-AUC 或 AP 可作为补充，标明具体实现。VisA 官方 PR 曲线面积与 `average_precision_score` 不应混称。
- 空掩码图的 Dice/IoU 处理方式要写清；正常图的错误不能因为只统计异常图而被隐藏。
- 轮数、最优权重、阈值和后处理均通过训练/验证确定，测试集不用于选择。第一轮探索可单种子，最终关键结果在资源允许下检查重复性并报告波动。

## 7. 可行性、学习收益与风险

| 风险 | 当前判断 | 应对 |
| --- | --- | --- |
| 基础 PyTorch 到完整分割工程有学习跨度 | 中等，数据与评价容易比接模型更费时间 | 先展示样本和掩码，再少量训练图过拟合检查，最后完整基线 |

| 数据较少、缺陷很小 | 可能过拟合或评价波动 | 保持独立验证，保留原分辨率样例，记录错误而不只追平均分 |
| PCB 与导师对象措辞不一致 | 尚未澄清 | 用真实样例和题目边界尽早讨论，不拖到材料定稿 |
