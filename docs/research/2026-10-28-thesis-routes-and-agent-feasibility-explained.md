# 两条论文路线详解：技术、开发训练难度与 Agent 辅助

初稿：2026-10-28；更新：2026-10-29（Asia/Shanghai）。结合“毕业与学习优先、Python 为主、难度适中、希望积累求职能力”的目标编写。本轮核对了官方论文与代码，没有执行模型训练；显存配置和难度等级是实施建议。

**最新状态：用户已选择以有监督分割为当前讨论主线。**异常检测作为备用背景保留。请结合[按实际顺序排列的阅读与开题准备](./2026-10-29-supervised-segmentation-reading-and-proposal-plan.md)和[跨电脑接续摘要](./2026-10-29-conversation-handoff.md)阅读；无需重新在两条路线间作初始选择。

## 1. 那句话的准确含义

“U-Net → SegFormer”表示：先用 U-Net 完成一个可靠的监督分割基线，再在相同任务与划分上训练 SegFormer、比较结果，并选择其中一个深入研究。两个模型通常独立运行，箭头不是把它们串接起来，也不意味着必须由 U-Net 给 SegFormer 生成标签。

两者各自输入同一套原始图像，使用训练集人工掩码计算损失，各自更新参数、保存权重。共享的是数据划分与评测流程；U-Net 阶段得到的是基线成绩、错误案例和可靠工程流程，不是供 SegFormer 使用的“基础数据”。推理时只输入待检图像，人工掩码用于评测。

“接受 PCB”是此前选用 VisA PCB 时的对象匹配问题，不是网络限制。全监督分割使用训练图及像素标注属于其任务设定；如果导师没有提出 normal-only 要求，不自行把使用标注变成额外审批环节。严格限定单体元器件时，应寻找相应监督数据，而非自动放弃分割。

“PatchCore → Dinomaly”同样是先易后难：先通过 PatchCore 学会正常特征、异常分数和热图，再用 Dinomaly 学习可训练的视觉 Transformer 与特征重建。

**两套方案各选一条深入即可，不需要同时完成四种模型。**

| 比较点 | U-Net → SegFormer | PatchCore → Dinomaly |
| --- | --- | --- |
| 要学什么 | 哪些像素属于缺陷 | 正常外观的特征规律，以及哪里偏离规律 |
| 训练数据 | 正常图＋缺陷图＋缺陷位置掩码 | 目标数据集中的正常图；另需说明外部预训练数据 |
| 缺陷掩码的作用 | 直接监督参数学习，也用于验证与测试 | 通常用于最终定位评测；不能默认用于 normal-only 调参 |
| 输出 | 各像素属于缺陷的概率／得分，再得到区域 | 异常分数图与图像分数，再得到报警与定位 |
| 学习优势 | 完整监督训练流程直观，便于学习常见视觉任务 | 工业缺陷稀缺设定自然，适合学表征、距离、重建 |
| 主要困难 | 标签数量、类别不平衡、小缺陷与过拟合 | 正常变化误报、异常分数校准、训练与评测协议 |

输出缺陷轮廓属于分割／定位；是否正常属于图像级判断。两个任务可以在同一系统中提供，但指标和阈值应分别定义。

## 2. 用同一个“划痕”例子理解两条路线

### 2.1 有监督分割

假设一张 PCB 图上有一条划痕，数据提供一张同尺寸掩码：正常位置为 0，划痕位置为 1。

训练时：输入图像 → 网络预测每个像素 → 将预测与掩码比较 → 计算损失 → 反向传播 → 更新网络。

例如一张缺陷图中，模型漏掉划痕会受到损失惩罚；在正常图上乱画缺陷也会受到惩罚。经过多轮学习，模型尝试从已标注图像中学到可泛化的缺陷外观。

这条路线有明确的监督信号，比较容易理解“数据、模型、损失和参数更新”之间的关系。不过未见过的新缺陷是否能检出，仍取决于它和训练数据的关系，不能保证任意缺陷都识别。

VisA 官方提供允许正常与异常图参与训练的 high-shot 协议；采用这个协议时，可以使用已有掩码，不需要先手工重标整套数据。[VisA 官方仓库](https://github.com/amazon-science/spot-diff)

### 2.2 正常样本异常检测

训练阶段只提供合格产品。模型学习正常外观的特征；测试时遇到划痕，希望划痕区域与正常规律差异较大，从而产生高异常分数。

这减少了训练前收集各种真实缺陷的要求。可是它仍需要异常样本检验效果，也必须有明确的“哪些变化是允许的”概念：正常反光或姿态变化可能被误判，外观接近正常的缺陷也可能漏检。

文献常称它为无监督工业异常检测；严格讲，通常仍已知训练样本正常，具体实现还可能使用外部预训练。报告中最好直接说明“目标数据只使用正常图训练”，避免把训练条件说得过于宽泛。

## 3. CNN 与 U-Net：先学会完整训练

### 3.1 CNN 是什么

CNN 是卷积神经网络。卷积层用一组可学习的小滤波器处理局部区域，并在图像不同位置共享参数。较浅层通常提取边缘、颜色和纹理等特征，较深层逐步组合出更复杂的结构。

以 3×3 卷积为例，它每次处理一个局部邻域；经过多层卷积、下采样等操作，一个特征能间接综合更大的区域。卷积并不是只能“看局部”，但它的信息交互方式与自注意力不同。

你需要理解的核心是：输入输出张量形状、卷积通道、下采样、感受野、激活函数、归一化，以及训练怎样改变卷积参数。

### 3.2 U-Net 是什么

经典 U-Net 是用于分割的 CNN 架构，主要包含：

- **编码器：**逐步降低空间尺寸，提取更抽象的特征。
- **解码器：**逐步恢复空间分辨率，预测每个位置的类别。
- **跳跃连接：**把编码器中较高分辨率的信息送到解码器，帮助恢复细节和边界。

示意尺寸可以是 `256×256 → 128×128 → 64×64 → … → 256×256`，具体层数和通道取决于实现。它适合作为缺陷分割的起点，因为输出直观，结构清楚，也有成熟实现。[U-Net 原论文](https://arxiv.org/abs/1505.04597)

实践中可以使用带 ImageNet 预训练编码器的 U-Net 变体，例如 ResNet18／34 编码器。预训练提供初始特征，再用你的缺陷图像微调；这与从随机参数开始训练不同。可用 [segmentation_models.pytorch](https://github.com/qubvel-org/segmentation_models.pytorch) 实现，不需要先手写完整 U-Net。

### 3.3 为什么它覆盖“完整监督训练流程”

为了训练 U-Net，你会实际完成：图像和标签读取、训练划分、同步增强、前向计算、损失、反向传播、优化器更新、验证、保存、加载和测试。这些步骤之后可以迁移到 SegFormer，也能迁移到其他监督视觉项目。

一个常见二值分割设置是两类输出，标签为 0／1，用交叉熵作为基础损失；研究前景稀少时，可以再评估类别权重或 Dice 等。输出也可以设计为单通道配 BCE，但两种设置的标签、激活和损失要配套。

## 4. 注意力、Transformer、ViT 与 SegFormer

### 4.1 注意力是机制

自注意力根据当前输入，计算不同位置的特征之间怎样交换信息。每个位置生成 Query、Key 和 Value，通常简称 Q、K、V：Q 与 K 决定关联权重，再用权重汇总 V。

标准缩放点积注意力为：

`Attention(Q,K,V) = softmax(QKᵀ / sqrt(d)) V`

对图像而言，可以理解为一个区域在更新自己的特征时，综合其他区域的信息。这可能帮助判断某段纹理是否与周围结构协调，但“有注意力”并不自动等于能发现缺陷。[Attention Is All You Need](https://arxiv.org/abs/1706.03762)

注意力权重图与缺陷概率图也不相同。可视化注意力有学习价值，但不能直接当作已正确定位缺陷的证据。

### 4.2 Transformer 是架构

Transformer 模块一般组合注意力、前馈网络／MLP、残差连接和归一化，并堆叠多层。注意力负责特征之间的交互，MLP 等模块进一步变换特征。

因此“学注意力”和“学 Transformer”可以在同一个模型里完成。你不需要先实现一个语言模型，再学习视觉 Transformer。

### 4.3 ViT 是视觉 Transformer 的代表

原始 ViT 将图像分成 patch，再转成 token 序列，交给 Transformer 处理。例如 224×224 图像按 16×16 分块，得到 14×14＝196 个图像 token，再按架构加入位置等信息。[ViT 原论文](https://arxiv.org/abs/2010.11929)

这些 token 携带学习到的视觉特征。分类模型可以将信息汇总为图像类别，分割和异常定位则需要保留空间对应关系。patch 很大或输入缩得太小时，小缺陷可能在表征中变得不明显。

### 4.4 SegFormer 是具体的分割模型

SegFormer 使用分层 Mix Transformer（MiT）编码器，输出多尺度特征，再通过 MLP 分割头融合并预测。它不是把 U-Net 的卷积原样替换成标准 ViT；它有自己的分层结构、特征处理和解码方式。[SegFormer 原论文](https://arxiv.org/abs/2105.15203)

“U-Net → SegFormer”的学习价值在于：数据与评价流程大体复用，你可以集中理解编码器怎样从卷积结构转向 Transformer，以及多尺度特征如何用于分割。

建议先用 B0，优先利用预训练权重；改变分类头以适配背景／缺陷两类，再微调。维护中的 [Hugging Face 实现](https://huggingface.co/docs/transformers/model_doc/segformer) 提供 PyTorch 模型、处理器与权重入口。

开发中重点检查：掩码映射为 0／1；`do_reduce_labels=False`；模型输出恢复到标注尺寸；图像与掩码同步增强；不要把缺陷 255 错当成忽略标签。

## 5. PatchCore：通过正常特征建库检测异常

PatchCore 可以按四步理解：

1. 用冻结的预训练 CNN 提取正常图像的局部特征。
2. 将训练图各位置的特征汇集起来。
3. 用 coreset 等采样保留有代表性的正常特征，建立记忆库。
4. 对测试图提特征，查找正常库中的近邻；距离越大，通常异常分数越高。

这里的“记忆库”主要存特征向量，不是简单存所有原图；“coreset”用于缩减库规模。经典设置不通过工业训练数据反向传播更新骨干，所以建库与 U-Net 的梯度训练是两类操作。[PatchCore 作者代码](https://github.com/amazon-science/patchcore-inspection)

它适合快速获得一个较强基线；不过训练图多、输入分辨率高或特征库大时，特征提取、采样与近邻搜索仍可能耗费显存和内存。作者说明多数原实验约在 11GB 显存范围内，高分辨率会增加开销；这不能直接作为 8GB 卡运行保证。[作者资源说明](https://github.com/amazon-science/patchcore-inspection#requirements)

## 6. Dinomaly：使用预训练 ViT 做特征重建

Dinomaly 的主要链路是：图像 → 冻结的 DINOv2 编码器 → 特征瓶颈与可训练重建网络 → 比较原始和重建特征 → 形成异常图。[作者项目](https://github.com/guojiajeremy/Dinomaly)

**DINOv2** 是自监督视觉预训练方法及其模型系列。你的任务使用作者已经训练好的权重，不重新完成大规模预训练。[DINOv2 论文](https://arxiv.org/abs/2304.07193)、[官方代码](https://github.com/facebookresearch/dinov2)

在 Dinomaly 中：

- 编码器从正常图像提取不同层的特征，默认冻结。
- 瓶颈与解码器学习重建正常特征，需要反向传播。
- 推理时计算原特征与重建特征差异，希望异常区域产生更明显差异。

重建的是特征，通常不是直接把 RGB 图像复原。异常也可能被很好地重建，所以瓶颈、重建约束和特征选择都很重要，不能把原理理解为任何缺陷都会天然产生高误差。

作者类别分别训练脚本默认：ViT-B/14、resize 448 后裁到 392、batch 16、每类 5,000 次迭代；可训练部分包括 MLP 瓶颈和 8 层线性注意力解码器。[作者训练配置](https://github.com/guojiajeremy/Dinomaly/blob/master/dinomaly_mvtec_sep.py)

因此它比 PatchCore 更适合练训练过程，也更费理解与调试。原项目使用 RTX 3090 24GB，但这不是最低显存声明。小卡先用 Small、batch 1—2、224／280 尺寸试跑属于可尝试的学习配置，效果与显存要实测；缩小 batch 后训练步数和总样本暴露量也会改变。

## 7. 开发、训练和学习难度

以下按“使用成熟开源实现、单类别迁移、有 Agent 辅助”评价，1 较易、5 较难。这是相对工程判断，不是模型性能排序。

| 方法 | 开发接入 | 训练／建库资源管理 | 原理学习 | 主要难点 |
| --- | ---: | ---: | ---: | --- |
| U-Net＋预训练小编码器 | 2 | 2—3 | 2—3 | 图像与掩码、损失、类别不平衡、小缺陷 |
| SegFormer-B0 | 3 | 3 | 3—4 | 预训练适配、多尺度特征、输出尺寸、注意力 |
| PatchCore | 2—3 | 2—3；高分辨率时可更高 | 3 | 特征库、近邻搜索、分数和阈值、依赖兼容 |
| Dinomaly | 4 | 3—4 | 4 | 冻结与训练边界、多层特征、重建损失、显存和旧代码适配 |

**你的首选路线总体为可分阶段完成的中等难度。**困难主要来自做对数据与实验，而不是需要编写新型底层算子。备选路线的 PatchCore 容易起步，但深入 Dinomaly 后，机制和训练调试通常更复杂。

### 7.1 对小显存单卡的起步建议

| 方法 | 可尝试的流程核验配置 | 后续怎样扩大 |
| --- | --- | --- |
| U-Net | ResNet18／34 编码器，256 输入，小 batch | 根据缺陷尺寸升到 512 或采用裁块 |
| SegFormer | B0，256 输入，batch 1—2，可评估混合精度 | 测量后提高到 512；确认细节收益再加模型规模 |
| PatchCore | 单类别，224／256 输入，小批量提特征，受控库大小 | 同时记录库规模、内存、采样和搜索耗时 |
| Dinomaly | ViT-S/14，224／280 输入，batch 1—2 | 若分辨率和正式训练预算需要，再用云 GPU |

这些只是试跑建议，尚未在目标机器验证。流程核验的小分辨率配置不一定适合正式缺陷检测；放大输入可能明显增加资源开销，必须结合缺陷尺度选择。

### 7.2 训练多久，应该怎么估

现在没有可靠的本机耗时数据，不能承诺几个小时或几天。可以先完成数据和前反向检查，再测稳定阶段 50—100 步的平均耗时：

`总训练时间 ≈ 总优化步数 × 平均每步时间 + 验证、保存等时间`

按 epoch 训练时：`每轮步数 = ceil(训练样本数 / batch)`；若采用随机裁块或重复采样，还要按实际采样器计算。PatchCore 则分别记录提特征、coreset 和近邻搜索时间。

同一模型在更大分辨率、更小 batch、更多类别时，耗时会变化。Agent 可以自动测量和记录，不能凭模型名称给出可信预算。

## 8. Agent 能帮到什么程度

**可以用编程 Agent 辅助，而且这类已有公开数据、成熟代码与明确指标的项目很适合这样合作。**Agent 是开发与实验助手，不需要成为检测模型本身的一部分，也不需要为此另建复杂 Agent 系统。

| 工作 | Agent 可承担的内容 | 你需要理解和验收的内容 |
| --- | --- | --- |
| 数据检查 | 统计数量／尺寸，核对图像掩码配对，生成样本拼图和划分清单 | 标签含义、研究对象、正常与缺陷定义 |
| 环境与工程 | 建 Python 环境，适配依赖，组织 Dataset、配置和日志 | 使用哪个实现、权重与版本，差异是否记录 |
| 基线实现 | 调用成熟模型，编写训练、验证、保存和推理代码 | 输入输出、损失、哪些参数在训练 |
| 小实验与调试 | 检查梯度，做少量样本过拟合，定位尺寸／显存错误 | 排错结果是否证明标签和训练流程正确 |
| 正式训练 | 按固定配置运行，监控日志，保存检查点和资源信息 | 训练预算、模型选择规则、测试数据是否被提前使用 |
| 实验整理 | 批量运行对照、汇总指标、保存热图和失败案例 | 是否公平、指标定义是否正确、改进是否稳定 |
| 论文与演示 | 整理方法说明、图表、Python 推理界面和重跑说明 | 引用、结果与结论真实性，能否独立答辩 |

可以大量依赖 Agent 编写常规代码，但不宜把论文研究决策完全交给它。代码成功运行、loss 下降或热图好看，都不能代替独立验证与正确指标。

你至少需要能回答六件事：数据如何划分；标签是什么；输入和输出形状；损失怎样计算；哪些参数会更新；测试指标怎样得出。并不要求背出所有实现细节，但要能解释模型为什么可能发现缺陷，以及它在哪些情况下会失败。

### 8.1 一种适合学习的协作节奏

1. 让 Agent 先检查并展示 20 组图像与标签，解释读取逻辑。
2. 用成熟库建立最小基线，打印关键张量形状。
3. 在少量训练图上验证能否过拟合，再接完整划分。
4. 完成一次固定配置训练、保存、加载和独立推理。
5. 由你和 Agent 一起看误报漏报，再决定下一项改变。
6. 保持数据和指标不变，加入第二种模型，形成可信对照。

### 8.2 可直接给 Agent 的任务例子

> 请基于 VisA PCB1 官方 high-shot 划分，用 Python/PyTorch 和现成 U-Net 实现建立单类别二值分割基线。先检查原图与掩码、生成可视化，确认 0 为正常、1 为缺陷。从官方训练集划出固定验证集，测试集不参与模型选择。先用少量训练图验证训练流程，再完成可配置训练、权重保存与加载、Dice/IoU 评估和误报漏报可视化；逐步解释张量形状、损失和训练参数。

随后可让 Agent 在同一套数据与评测上接入 SegFormer-B0。这比一次要求它“自动完成所有模型与论文创新”更便于发现问题，也更利于你掌握代码。

## 9. 为什么首选仍然是 U-Net → SegFormer

对你的目标，首选路线的优势是反馈直接、训练知识通用、难度容易逐步增加：先从 CNN 学会完整训练，再在相同任务上学习 Transformer，不需要同时改变数据、监督方式和评价体系。

备选路线同样可行，也能学到现代视觉技术，但它更强调正常建模、异常分数和特征重建。若导师更重视缺陷稀缺，这条路线的任务设定更合适。

当前沿监督主线检查对象与数据是否匹配，建议从 U-Net 开始；若最终限定单体零件，应调整匹配数据，而非把 PCB 当成网络要求。开题前优先一个可重跑基线、真实错误分析和后续计划。导师与学校的要求尚待对齐，这不是对开题通过的保证。

论文研究可以逐步形成：基线与问题分析 → 一项针对性适配／改进 → 对照与消融 → 第二类别验证 → Python 演示。创新与章节深度按导师要求收敛，不需要一开始提出全新架构。

原选题建议见 [开题路线建议与学习计划](./2026-10-28-electronic-defect-thesis-proposal-guide.md)。

## 10. 毕业论文与开题怎样组织（10 月 29 日补充）

论文围绕一个具体缺陷问题表达：研究对象与任务 → 成熟基线与失败分析 → 一项针对性改进 → 对照、消融、跨类别与成本评测。U-Net 可作参考基线，SegFormer-B0 为拟深入候选，不把两个模型写成两个独立课题。

多模型对照回答“整套方案表现如何”；原始主模型与改进模型、内部消融回答“改动是否有效、由哪部分带来”。前者不能替代后者，也不能仅凭 U-Net 与 SegFormer 的分数差将全部收益归因于注意力。

暂定宽口径题目可用《面向电子组件外观缺陷的图像分割方法研究》，但它是建议，尚未获用户或导师定题。细小缺陷漏检、边界恢复、正常区域误报也是候选问题，须由样本与预实验支持，不写成已经观察到的结论。

开题前优先完成一个任务定义、一份数据／划分说明、一个可重跑基线、真实预测与错误案例、一项初步改进假设和后续验证计划。第二模型有余力再做，不能为凑模型数牺牲数据与指标正确性。这是建议准备目标，不是学校统一通过标准；不自行增加两个研究点、发表或独立系统要求。

SegFormer 是 2021 年成熟方法，当前可行性不等于已证明先进性。近年阅读补入 DS²A-Former（TIM 2025）、SegMAN（CVPR 2025）；是否新增近年对照或更换主模型，依据问题与适配成本再决定。无需在开题前同时训练所有阅读清单模型。

可向导师说明（当前尚无实验成绩的版本）：

> 我拟聚焦电子组件外观缺陷的像素级分割，前期采用 U-Net 建立参考基线，以 SegFormer-B0 为拟深入候选，同时调研近年工业和通用分割方法。通过样本与预实验分析细小缺陷及误报问题，再确定一项改进，并用原始模型、相关近年方法、消融和第二类别验证。当前已完成资料研究，训练结果尚未取得；最终对象与工作量需与导师对齐。
