整理日期：2026-11-07。语言：中文。用途：个人学习、导师讨论与开题问答准备。

**当前主入口：[研究与学习主文档](thesis-research-and-study-guide-zh.md)。**最新设计表初稿、学习顺序和资料清理以主文为准；本文作为22题细节附录保留。

## 使用说明

本文对应此前讨论的 22 个开题问题，给出可用于组织口述的参考答案，并说明依据、尚未解决的问题及追问方向。本文不是已获导师认可的最终研究方案，也不代表学院正式评分标准。

请注意四类状态：

- **已核实事实**：来自项目配置、代码、保存结果和验收记录。
- **文献结论**：注明论文及适用条件，不自动外推为本项目结论。
- **拟开展研究**：尚未实施或尚未选定的方案，不能讲成已有成果。
- **个人掌握情况**：需要你自己核对；项目由 AI/Agent 协助完成，不代表你已亲自实现、阅读或掌握全部内容。

本文中的第一人称口述稿是参考表达。涉及“我已经完成、理解、阅读”的内容，应按你的实际情况调整。

当前采用导师建议的题目：**《PCB外观缺陷检测方法研究》**。建议总问题为：

> 如何将预训练视觉表征有效适配于 PCB 外观缺陷检测，提高局部缺陷的分割与定位精度，并提供与模型实际决策一致、可验证的判别依据？

**有限算力只作为实验实施条件，不预设为论文核心问题。**轻量化、参数效率是否成为研究内容，应由选题和实验决定。

## Q01

**问题：请用一分钟说明，你到底研究什么？**

**参考回答：**

> 我研究 PCB 外观缺陷的像素级定位，重点关注缺陷漏检和正常结构误报。当前已经建立 VisA PCB1 上的 SegFormer-B0 监督分割基线。后续拟检验预训练视觉表征的任务适配，并研究与实际判别过程相联系的证据方法。希望通过受控实验说明方法改善了什么错误、在哪些条件下有效。DINOv3、具体适配及解释性实验目前仍属于后续工作。

**说明：**先讲对象与问题，再讲技术。不要将整个工业电子检测、电气功能检测或未知缺陷识别都包含进来。当前二值掩码没有区分不同缺陷类别。

**准备材料：**正常/异常原图、GT、预测各一例；一张已完成与拟开展的路线图。

## Q02

**问题：题目写“缺陷检测”，为什么实际采用分割？**

**参考回答：**

> “检测”是题目的应用表述，我采用的具体技术任务是缺陷分割。像素掩码可以表达缺陷的位置、形状和范围，与现有标注匹配。当前先评价定位；如果需要判断整板是否异常，再定义从像素概率、连通区域到图像判定的规则，并单独评价。

**说明：**分类回答整图是否异常，框检测输出框，分割输出像素范围。选择分割不意味着必须证明其他任务无用，而是说明它为什么适合当前目标。监督分割与图像决策结合已有工业研究先例，见 [L12](#l12)。

**可能追问：**“输出掩码以后怎么用于检测？”应回答具体用途，如辅助定位和复核；若还未实现判废流程，要明确说明。

## Q03

**问题：你要解决什么具体困难？“提高精度”太笼统。**

**参考回答：**

> 已有基线显示部分缺陷没有被正确定位，也存在正常区域误报。我拟优先研究 PCB 复杂正常结构与局部缺陷之间的区分问题，检验错误是否与细节保留、特征适配或监督方式有关。目前原因尚未确认，因此先在 train/val 上进行错误分组和控制实验，再确定主要改动。

**说明：**“有漏检”是事实；“漏检由缩放造成”是原因假设。当前 global IoU 与 macro IoU 不同，也不能单独证明小缺陷是主要瓶颈。

**待补证据：**按事先定义的尺度、对比度或结构位置分组；对照缩放前后缺陷可见性；固定其他条件比较输入尺度。分组标准应可重复，不能看结果后随意划分。

## Q04

**参考回答：**

> 我优先关注 SPD、SuperSimpleNet 和 Gharbage 等人的工业迁移研究。SPD 与我的 VisA 监督协议最接近，帮助我解释局部缺陷信息与通用预训练目标的差异；SuperSimpleNet 提供冻结特征、适配和缺陷预测的已有方法基础；Gharbage 的研究说明冻结迁移未必占优，适配方式需要检验。国内 PCB 方面，我补充参考 CADNet，但它需要无缺陷参考图，与我当前单图任务不同。

**逐篇用途：**

## Q05

**问题：这些技术都有人研究过，你新增什么？**

**参考回答：**

> 预训练骨干、冻结、分割头和适配器属于已有技术基础。我拟研究的贡献，应落在针对明确 PCB 错误的一项适配机制，以及一项与实际判别路径相关的证据方法。当前还不能宣称两项创新已经成立，需要将候选机制与最近工作比较，并通过控制实验验证。

**说明：**创新可能来自明确问题下的新机制、约束或有充分证据的改进；不能仅以模型更换、常规模块拼接或参数调优命名为新方法。更换产品和数据集，也不会自动使已有方法成为原创。

**待填写的贡献句式：**“针对【已确认错误】，拟通过【具体机制】改善【明确目标】，并与【最接近方法/简单替代方案】比较，验证【作用及代价】。”

## Q06

**问题：为什么选择 DINOv3？冻结有什么研究意义？**

**参考回答：**

> DINOv3 提供可迁移的密集视觉特征，因此我将它作为候选表征。冻结骨干、训练简单分割头，可以先检验这些特征直接包含多少可被下游利用的信息。再以同一骨干比较适配方案，判断是否存在可改善的任务匹配问题。目前没有 PCB 实验结果，不预设它优于 SegFormer。

**说明：**[L08](#l08)提供通用特征依据，[L05](#l05)、[L06](#l06)提供相邻工业任务的先例，[L03](#l03)提醒迁移存在条件。冻结具有实施意义，但冻结本身不是论文贡献；“训练参数少”也不保证推理更快。

**可能追问：**若效果不佳，应区分特征缺少信息、分割头不足、预处理问题和训练设置问题，不凭一次结果给整个模型家族下结论。

## Q07

**问题：拟提出的方法到底是什么？请指出改在哪里。**

**当前真实状态：已在[主文第3节](thesis-research-and-study-guide-zh.md#s3)形成局部细节适配、结构约束正常参照两项候选草稿，但尚未实施或最终选定。**方法新颖性、诊断依据及参照条件仍需验证。

**参考回答：**

> 拟先用冻结 DINOv3 加简单分割头建立独立对照。工作一的主要候选是在空间特征旁引入原图局部细节分支，通过适配接入统一预测头；工作二拟让训练正常参照的差异直接参与缺陷评分。两项草稿已有明确输入输出和对照，但还要检验错误成因、参考可配准性及与已有方法的差别，不能预先声称有效。

**可用于说明的流程：**

```text
图像 → 同步几何处理 → 预训练编码器 → 空间特征
                                      ↓
                         简单头 / 候选适配＋头
                                      ↓
                           缺陷 logits → 原图概率
```

**尚未确定的内容不能编造：**若主要瓶颈是细节受损，候选可能是尺度/局部细节处理；若特征有信号但无法区分正常结构，候选可能是特征适配或正常参考比较。上述是方向，不是已选定、已有效的方法。

**开题前应补齐：**一张主要候选结构图、一项机制假设、一组必要对照、失败判据。普通切块或增加分辨率可作诊断与基线，不自动等于方法创新。

## Q08

**问题：两项实质研究工作分别是什么？跑两个模型算吗？**

**参考回答：**

> 我拟围绕精度适配和判别证据组织两项相关工作。工作一针对明确的定位错误开展适配；工作二研究证据如何参与缺陷判断及其可靠性。两项可以共享数据和骨干，但应分别具有问题、方法和评价。SegFormer 与 DINO 的比较属于研究基础，不能简单按模型数量计算贡献。

| 内容 | 工作一：精度适配 | 工作二：判别证据 |
| --- | --- | --- |
| 主要问题 | 某类漏检/正常结构误报能否缓解 | 模型使用什么证据，证据能否核查 |
| 方法状态 | 局部细节适配草案，未验证 | 正常参照直接评分草案，配准与评价待核 |
| 主要比较 | 原方案、简单替代、适配方案 | 基础预测、普通参考/解释、拟方法 |
| 评价重点 | 定位、召回、正常误报和代价 | 相关性、忠实性、稳定性及任务表现 |

**当前缺口：**已有两项设计初稿，但方法新颖性、数据条件和评价可行性未获验证。导师说“最好有两个以上工作”，不能自行解释成模型数、章节数或论文篇数；需拿具体内容确认其预期。

## Q09

**问题：你的可解释性究竟解释什么？**

**参考回答：**

> 我关注模型把某一区域判为缺陷时实际使用的视觉依据，例如哪些区域或正常参照差异参与了评分。缺陷掩码表达预测位置，解释研究需要进一步说明这些信息与判断的关系。它不等同于判断缺陷的制造原因。

**说明：**应先固定被解释的输出，如某一预测区域的缺陷得分。若正常参考差异进入评分，可展示实际使用的参考及其贡献；若参考检索只发生在预测之后，它不能自动解释原分割器。

**文献帮助：**[L09](#l09)说明不稳健依据可能影响工业模型；[L10](#l10)提示概念解释与像素分支需要分别说明。概率校准、不确定性与解释忠实性也应分开评价。

## Q10

**问题：怎样证明解释可信，而不只是热图好看？**

**参考回答：**

> 我拟分别评价解释与缺陷的相关性、对实际模型的忠实性，以及合理干扰下的稳定性。与 GT 重叠只能说明定位相关；还应检验改变关键证据后输出是否相应变化，并与等面积随机区域等对照，检查操作自身带来的伪异常。

| 评价目标 | 候选验证 | 结论边界 |
| --- | --- | --- |
| 相关性 | 与缺陷区域、人工标记依据比较 | 不单独证明模型真正依赖该依据 |
| 忠实性 | 正常参照替换或移除证据，并与随机区域比较 | 需定义具体输出和干预方式 |
| 伪影控制 | 正常→正常替换、边界处理对照 | 防止粘贴痕迹被模型当成缺陷 |
| 稳定性 | 轻微有效光照/位移变化前后比较 | 不能要求对改变缺陷本身的操作不敏感 |
| 模型敏感性 | 适用时做参数随机化等检查 | 一个检查通过不等于解释完全正确 |

**说明：**检查的是模型对干预的响应，不是制造过程的物理因果证明。若声称有助于质检人员，还需要真实复核任务证据；当前没有此类结果。参见 [L11](#l11)。

## Q11

**问题：为什么选 VisA？它能代表工业问题吗？**

**参考回答：**

> VisA 包含结构复杂的 PCB 板级外观图像，提供像素标注和正常/异常共同参与训练的官方协议，适合建立可复现的监督定位研究。它支持当前方法比较，但不能代表所有产线成像和缺陷分布。

**说明：**[L01](#l01)是直接依据。论文说明其缺陷通过人工制作模拟真实异常；数据缺少本课题目标产线的验收公差、跨批次与相机条件验证。因此可以研究公开基准上的方法，工业应用仍需补充数据。

**可能追问：**为什么不选其他 PCB 数据？应比较对象（带元件板/裸板）、标注（框/像素）、监督协议和数据可用性。不能仅因为名称都有 PCB 就视为同一问题。

## Q12

**问题：你属于有监督、自监督还是异常检测？**

**参考回答：**

> 要分开预训练和下游阶段。DINO 的预训练是自监督表征学习；我的下游分割头使用正常图和真实缺陷掩码训练，因此当前任务是有监督二值分割。正常样本训练的异常检测、目标域零样本迁移以及 episodic few-shot，是不同设置。

**说明：**当前是官方 high-shot 派生协议。训练优化部分只有 48 张异常图，是此协议与验证划分的结果，不能据此改称官方 few-shot。

**若研究标注效率：**需要在固定评价人群下改变训练标注预算，重复抽样并保持比较条件。使用官方其他协议时，要说明测试集也可能变化，不能混淆成仅训练样本量不同。

## Q13

**问题：train/val/test 怎么划？已经看过 test 后怎么办？**

**参考回答：**

> train 用于更新参数，val 用于选模型和开发决策，test 用于冻结方案后的评价。目前使用固定清单，先划原图再做变换或裁块。PCB1 的 test 指标和失败图已查看，后续会披露接触记录；方法开发、阈值与后处理选择回到 train/val，有条件时补充新的独立评价。

**说明：**项目 v2 处理了已审查的同实物风险分组，但不能据此承诺所有潜在实物关联和近重复都已完全排除。对已知同源图，应该按组划分。

**不能采用的做法：**从 test 抽图进入训练；依据 test 反复选择模块或阈值；重新命名旧 test 后称完全盲测。技术复核与方法择优是不同活动，原项目记录应保留。

## Q14

**问题：DINO 超过 SegFormer，就证明自监督预训练更好吗？**

**参考回答：**

> 不能。两套方案同时改变结构、规模、预训练数据、空间特征和下游更新范围。它们可以回答“哪套完整迁移方案在当前条件下更合适”，不能单独证明自监督、架构或冻结方式更好。

**说明：**整体对照需统一数据与原图评价；机制验证则尽量固定骨干、头部和输入设置，只改变目标因素。例如在同一 DINO 下比较简单头、常规适配与拟方法。若无法严格隔离预训练条件，就明确结论范围。

**公平不等于全部数值相同：**不同模型可使用各自合理的学习率与归一化，但调参范围、验证选择和资源代价要透明，避免一方精调、另一方随意训练。

## Q16

**问题：你报告的指标到底说明什么？**

**参考回答：**

> 我主要评价缺陷类的定位效果。全局 IoU 汇总全部图的 TP、FP、FN；异常图 macro IoU 对异常图等权，两者权重不同。像素 recall 说明找回多少缺陷像素，不能直接解释成检出多少坏板。正常图存在任意 FP 的计数，也不能在没有板级规则时称为产品误剔率。

**应掌握的公式：**

```text
IoU       = TP / (TP + FP + FN)
Dice      = 2TP / (2TP + FP + FN)
Precision = TP / (TP + FP)
Recall    = TP / (TP + FN)
```

例如 TP=30、FP=10、FN=20，则 IoU=0.5、Dice≈0.667、precision=0.75、recall=0.6。应能解释每个错误的实际含义。

**项目数字：**test 像素 recall≈0.739；32/402 张正常图有任意 FP。若要报告板级指标，需要先固定报警/判废规则；若报告缺陷实例召回，需要另外定义区域实例及匹配标准。

**指标陷阱：**当前 test 中所有像素都预测正常，像素 accuracy 仍约 99.95%，但缺陷像素 recall=0。当前实现将正常图空 GT 且空预测的 IoU/Dice 记为 NA，正常误报另行报告，避免大量正常背景掩盖定位错误。

## Q17

**问题：单类别、单 seed 的提升能推广多远？**

**参考回答：**

**说明：**多 seed 主要观察优化随机性；按独立图像/已知实物组做重采样，主要观察测试样本不确定性。两者不同。不能将大量相关像素当作同等数量的独立工业样本。

**准备：**核心模型的重复实验计划、逐图收益与失败分析、结论适用范围。40 张异常图不足以验证极低的长期漏检率，不能靠漂亮均值作这种保证。

## Q19

**问题：请从一张原图开始，讲清数据、参数和计算流程。**

**参考回答：**

> 目前项目将原始非零缺陷标签合并为 1，正常图构造全零标签；图像与标签同步变换并 letterbox。模型利用预训练编码器和新建二类解码头产生 logits，训练时计算 CE 与前景 Dice。评价时将 logits 恢复到原图再计算概率、阈值和指标，直接与原始尺寸 GT 比较。

**你应理解的实现细节：**

| 环节 | 当前实际实现及意义 |
| --- | --- |
| 标签 | 0=背景/正常，1=缺陷；255 只用于 letterbox padding 忽略区 |
| 几何 | 原图 1404×1070，内容缩放至 512×390，上下各补 61 像素 |
| 插值 | RGB 图像用 PIL BILINEAR；标签用 NEAREST，避免生成虚假类别 |
| 预处理 | processor 关闭重复 resize 和 reduce_labels，保留背景 0 |
| 初始化 | MiT-B0 预训练编码器；整个 decode_head 新建，不仅替换最后一个分类层 |
| 权重核查 | 192/192 个编码器张量匹配；源 checkpoint 另 2 项为未使用的原分类头，不是缺少 2 项编码器权重 |
| 更新范围 | 当前 SegFormer 全网络微调，共 3,714,658 参数 |
| 损失 | CE(ignore=255)＋0.5×正 GT 图的前景 Soft Dice；正常图通过 CE 约束误报 |
| 选模 | val 原图全局前景 IoU 最高，分数相同保留更早轮次 |
| 原图评价 | logits 插值至 512→裁 padding→插值到原 H/W→softmax→前景概率≥0.5 |
| 评价 GT | 直接使用原图尺寸的二值 GT，不把缩小后的标签放大当作评价真值 |

**关于拟做 DINO：**512×512、patch=16 对应 32×32 patch 网格，需要正确排除额外 token。冻结应核查 requires_grad、优化器参数、梯度和更新前后权重；eval() 本身不冻结参数。头部仍需正常反向传播。以上 DINO 检查是待实施要求，不是已有记录。

**准备材料：**手画数据流，能定位 [E04—E06](#evidence) 中对应函数；理解 CE/Dice 的作用及其局限，无需把背诵版本号当作主要学习目标。

[官方论文](https://openaccess.thecvf.com/content/CVPR2022/html/Roth_Towards_Total_Recall_in_Industrial_Anomaly_Detection_CVPR_2022_paper.html)。

正常局部特征记忆库和最近邻距离参与评分，为正常参考比较提供既有基础。帮助讨论工作二与创新边界。它采用正常样本训练，不自动解释独立 SegFormer 分支；仅展示相似参考也不构成新的解释方法。

### L14

**Wang 等：Real-IAD: A Real-World Multi-View Dataset for Benchmarking Versatile Industrial Anomaly Detection，CVPR 2024。**

[论文](https://arxiv.org/abs/2403.12580)。

国内团队提供多视角、大规模工业基准，帮助理解缺陷可见性及评价多样性。用于研究背景和扩展评估参考，不意味着当前课题必须改做多视角，也不证明现有方法已通过这些测试。

### L15

**Heckler-Kram 等：The MVTec AD 2 Dataset: Advanced Scenarios for Unsupervised Anomaly Detection，2025 年首次发布的基准论文。**

[论文](https://arxiv.org/abs/2503.21622)。

包含细小缺陷、复杂成像和光照变化测试，帮助说明同分布公开测试之外仍有真实挑战。其正常样本异常检测协议和 AU-PRO 等指标，与当前监督 IoU 不同，不能横比数值或拿它作为统一产线验收标准。

### L16

**Xie 等：SegFormer: Simple and Efficient Design for Semantic Segmentation with Transformers，NeurIPS 2021。**

[论文](https://arxiv.org/abs/2105.15203)；[作者实现](https://github.com/NVlabs/SegFormer)。

用于理解层级 Transformer、多尺度特征和轻量解码器，帮助讲清现有基线。它是通用分割结构依据，本身不证明 PCB 工业适用性，也不等于当前使用了整套已有 PCB 分割权重。
