## 1. 当前研究方向：哪些已经收敛

### 1.1 题目、对象与总问题

**当前题目按用户确认采用：《PCB外观缺陷检测方法研究》。**导师指导的工作方向为检测精度提升和可解释性；题目与下述具体缺陷分割任务分层说明。

具体任务是：以 PCB 板级 RGB 外观图像为输入，利用已有像素标注进行背景/缺陷二值分割，输出原图尺度的缺陷位置与范围。目前从 VisA PCB1、官方 2-class high-shot 的派生协议起步。VisA 的 PCB 包含元器件等复杂外观结构；当前结论限定于这些可见外观图像，不能自动推广到裸板断路/短路、内部焊点或电气失效检测。

建议总问题：

> 如何将预训练视觉表征有效适配于 PCB 外观缺陷检测，提高局部缺陷的分割与定位精度，并提供与模型实际决策一致、可验证的判别依据？

| 层次 | 当前口径 |
| --- | --- |
| 应用领域 | 工业视觉检测中的 PCB 外观缺陷检测 |
| 具体任务 | 有真实像素标注的监督二值分割；当前不输出缺陷类别 |
| 精度研究 | 减少缺陷漏检、控制正常区域误报，查明改动改善了哪些错误 |
| 解释研究 | 检查哪些区域或正常参照实际参与判别，以及依据是否可靠 |
| 技术入口 | 预训练特征迁移与任务适配；DINOv3 是候选，不预设必胜 |
| 结论边界 | 不涉及电气功能、内部焊点或制造原因诊断；公开数据结果不等于产线验收 |
| 实施条件 | 在职非全日制、Python/PyTorch 优先、难度适中；算力与时间列入可行性 |

**有限算力不放入核心研究问题。**只有明确研究精度与计算代价取舍，并完成对应实验时，效率才成为研究内容。没有小论文发表指标是已有个人记录，不替代学院最新正式要求。

### 1.2 导师反馈怎样理解

导师已支持工业视觉检测，建议题目《PCB外观缺陷检测方法研究》，并提出“检测精度提升、可解释性”“最好有两个以上工作”。当前沿用这一题目和两条研究主线；候选机制由文献、诊断与实验收敛，不要求先安排新的导师讨论。方法有效性、新颖性和工作量仍由实质研究说明。

目前按两项相关工作组织：**工作一研究检测精度提升，工作二研究可解释性。**特征适配是工作一的候选技术入口，评分绑定的正常参照证据是工作二的候选实现，不能用纯迁移对比或检索优化替代这两个目标。两项可以共用数据与模型，但要分别有问题、方法、比较和结论。两个模型、两个章节或多个工程阶段不自动等于两项贡献。

**本研究以 PCB 场景适配与应用问题为贡献重点。**可以复用已有骨干和模块，通过有依据的适配、预测流程或评价解决具体 PCB 困难，不要求每个组件原创。直接换数据集复现可作为应用验证；若要形成更强的论文贡献，应说明当前场景中现有方法的不足、处理的必要性、同协议收益与适用边界。方法、应用和系统贡献按实际成果分别陈述，不把“首次用于 PCB”当作未经查证的结论，也不保证仅凭两项草案就满足学位要求。

### 1.3 现实与文献依据

工业缺陷往往是正常产品中的局部差异。通用预训练提供可复用信息，但不保证这些信息能直接支持当前缺陷定位；适配、空间细节和监督条件都可能影响效果。相关研究已充分存在，本文不把“使用预训练模型”写成空白。

另一方面，分数较高仍可能依赖不稳健线索；核验判别依据有助于发现问题。**缺陷掩码回答哪里，模型解释回答依据什么，工艺诊断回答制造原因**，三者分开。直接相关文献及用途见[第 7 节](#s7)。

### 1.4 一分钟口述稿

> 我的题目是《PCB外观缺陷检测方法研究》，围绕检测精度提升和可解释性两项工作展开。目前从 PCB 外观缺陷的像素级定位切入，已完成 VisA PCB1 上的 SegFormer-B0 监督分割基线。精度方面，拟先建立 DINO 简单头对照，再针对实际错误选择适配方法；可解释性方面，拟研究与模型实际评分绑定、可核验的判别依据，正常参照是候选实现。具体机制仍需查新和实验验证，目前不预设 DINO 更好，也不声称已达到产线标准。

### 1.5 数据集的分工与可支持的结论

| 数据角色 | 当前安排 | 可支持与尚不能支持的结论 |
| --- | --- | --- |
| 方法开发与诊断 | 保留 PCB1 的现有 train/val/test 清单；方案和阈值用 train/val，历史 test 接触如实披露 | 可比较同协议方法及错误变化；单类别、40张异常 test、单seed不能独自支撑宽泛泛化结论 |
| 后续验证 | 在方法设计前确定至少一个尚未用于设计的其他 VisA PCB 类别，记录数据访问、监督预算和划分；具体类别待选 | 分别训练后验证可支持多类别适用性；未经目标域训练的跨板型迁移需要另立协议 |
| 扩展数据 | 仅在具体问题需要且标注/输入条件匹配时，补充一个独立数据集 | 框标注不能直接替代精细mask，配对模板会改变输入条件；不承诺同时跑全部工业基准 |

VisA high-shot 是合理的监督任务起点。当前研究可围绕“已有标注下的精度和依据”开展；若声称标注效率提升，再固定评价集和正常样本预算，做异常mask预算曲线与重复抽样。48张异常训练图本身不等于官方few-shot协议。

## 2. SegFormer、DINO 与两项工作的关系

| 内容 | 当前状态 | 在论文中的作用 |
| --- | --- | --- |
| SegFormer-B0 | 已完成并有验收记录 | 可信基线、统一实验平台、错误诊断入口；也可能承载后续改进 |
| 冻结 DINOv3-S/16＋简单头 | 待实施 | 独立迁移对照，检验固定表征中有多少信息能用于 PCB 定位 |
| 工作一：检测精度提升 | 设计草稿 | 针对具体错误选择特征适配等方法，检验精度收益及代价 |
| 工作二：可解释性 | 设计草稿 | 正常参照为候选，检验解释与实际评分的联系、忠实性、稳定性及覆盖范围 |
| 融合、预测集成、蒸馏 | 条件候选 | 出现互补证据且有必要时再讨论，不预设为必做 |

现有 SegFormer 工程包括数据、几何、训练、选模、原图评价与图表，公共部分可继续使用。它本身不自动构成方法创新，也不需要因为要研究 DINO 就废弃。后续新实验应单独归档，保留原基线作比较。

```text
共同数据与评价协议
  ├─ SegFormer-B0：已完成的独立基线
  └─ 冻结 DINOv3＋简单头：拟开展的独立对照
          ↓ 结合 train/val 诊断与文献
     工作一：检测精度提升（特征适配／局部细节为候选）
     工作二：可解释性（评分绑定的正常参照为候选）
          ↓
     对照、消融、解释验证、重复与独立数据 → 适用边界
```

该图表示研究依赖，不表示已决定把两种骨干融合。若 DINO 不适合，保留真实结果，并与导师讨论采用更有证据的载体；不自动取消原定对照，也不靠模型更新保证贡献。

## 3. 两项研究设计表初稿

### 3.1 初稿的定位

为方便开题，下面各给一个**主要候选**。工作一的目标是检测精度提升，PCB 表征适配与局部细节支路是待检验方案；工作二的目标是可解释性，评分绑定的正常参照是候选解释形式，位置/结构约束是待检验的参照选择方式。选取它们是基于已知错误和文献的建议，不代表已诊断原因或成立贡献。实现前先做 train/val 诊断与最近工作对照，未获支持时调整具体机制，保留精度和可解释性目标。

| 设计项 | 工作一：检测精度提升（候选：PCB特征适配） | 工作二：可解释性（候选：评分绑定的正常参照） |
| --- | --- | --- |
| 研究问题 | 如何针对已诊断的 PCB 错误适配预训练表征，改善缺陷覆盖并控制正常误报？局部细节是候选切入点 | 如何说明模型依据什么作出判断，并核验解释对实际评分是否忠实、稳定和覆盖充分？正常参照是候选解释形式 |

### 3.3 机制怎样讲清

工作一的草稿流程：

```text
RGB ──→ 冻结 DINO 空间特征 ──→ 对齐/投影 ─┐
  └──→ 局部卷积分支（较细网格）────────────┤
                            残差适配/融合 → 二类头 → 原图预测
```

增加局部分支只是候选机制；不会凭空恢复输入已丢失的内容，也可能放大正常纹理误报。需与简单融合、普通增容、尺度调整比较。若沿用已有结构，应明确技术来源，将成果据实定位为PCB适配/应用验证，并以具体问题、收益和边界支撑；若声称新方法，还需补充实质机制差异。

SegFormer 的漏检只能说明当前基线有改进空间，不能直接证明尚未实验的 DINO 也存在相同瓶颈。先建立 DINO 简单头并在 train/val 检查错误，再决定局部分支、其他适配方式是否有必要；目前不把“DINO＋RGB 支路”固定为工作一的最终结构。

工作二可用如下形式说明评分草稿：

```text
固定特征 z_p → 从训练正常库 M(p) 检索 → 距离 d_p → 单调映射 → 缺陷得分
```

例如 d_p 为待测块与允许参照集合中最近特征的距离；映射随距离单调增加。它便于追溯评分真正采用的参照，但不能因此宣称输出已是校准概率或解释了整套制造过程。映射和阈值由 train/val 确定。

**评分换刻度与新增判别信息要分开。**在同一打分单元上，若只对固定距离使用同一个严格递增标量映射，则这些分数的排序、AUROC／AP 和遍历阈值可得到的掩码集合均不变；映射后若还有插值、聚合或融合，需另核最终分数是否仍满足这一关系。它可用于工作点表达或另行验证的校准，不单独提供新的定位能力；固定数值阈值下分数变化也不能代替公平阈值比较。[数学性质推导]

这里有三个不同操作：**正常库**保存训练正常区域特征及来源索引；**空间约束**按对齐坐标筛选允许的参照；**特征近邻**在候选中找最相似的特征，用距离度量偏离。坐标相近不等于同一焊盘/线路结构，DINO特征相似也不保证参照语义正确。原图/坐标索引需与用于评分的特征绑定，才能展示真实参考。

[DINOSaur v2 §4.3—4.4、§5.3及表3](https://arxiv.org/html/2605.24251v2)已有“按位置组织正常特征→邻域筛选→最小欧氏距离评分”，并报告像素级 AUROC，是必须比较的直接近邻。不能再用“它只做图像判别、我增加像素定位”区分工作；其 normal-only 持续学习条件仍不同于当前 mask 监督 PCB，但换数据、监督或拟合映射不自动建立新机制。固定骨干、库容量、尺度和标注访问后，检验是否确有参照错配问题，以及候选处理相对全局近邻、DINOSaur 式邻域的任务收益与核验价值。

**关键数据条件：VisA 没有每张待测图逐一配对的“黄金正常板”。**不能假设已有完美对应参考。参照库只能来自训练正常图；先检验 PCB1 姿态、板型与配准是否支持位置约束。若不支持，位置约束候选不成立，应讨论改变机制或数据条件，不暗中增加人工标注任务。

正常板位移、反光或光照变化也可能增大距离；“偏离库中正常”不自动等于工艺缺陷。先在train/val检查匹配、缺陷覆盖和正常误报，对齐不可靠时可收缩或替换约束候选，不能仅为保留结构假设而换数据制造优势。

### 3.4 两项工作如何分别成立

工作一回答“怎样提高检测精度”；工作二回答“模型依据什么判断，解释是否可靠”。可考虑以下候选实现的 2×2 对照：

| 特征 | 普通分割头 | 参照判别 |
| --- | --- | --- |
| 原冻结特征 | DINO 简单头基线 | 先独立验证工作二 |
| 工作一适配特征 | 独立验证工作一 | 检验两者结合及相互影响 |

各条件下固定特征后再建对应训练正常库，避免混用特征空间。该表能检查机制独立性；创新性与工作量还需由方法差异和实验结果说明。

工作二的核心成功依据是可解释性验证，不以 IoU 必须上涨为前提；同时报告检测效果与计算代价，说明是否存在代价或权衡。若只有检索精度提升而没有解释对象、解释机制和可靠性实验，尚不能当作已完成可解释性工作。

### 3.5 解释验证的最小草案

解释对象先限定为某个区域的实际缺陷得分。拟比较：高证据区域用匹配正常块替换、等面积随机区域替换、正常区域替换；再做正常→正常替换控制拼接伪影。观察评分和预测变化，辅以适用的随机化检查。

DINO 的 ViT patch token 经全局自注意力处理，包含图像上下文；来源坐标只能追溯“实际检索了哪个 token”，不能证明所展示小裁剪中的像素完整决定评分。后续保留来源整图并标记 patch，区分特征检索路径核验与输入像素归因；做图像替换干预时重新提取整图特征，不能只替换缓存 token 后称为图像干预。[官方注意力实现](https://github.com/facebookresearch/dinov3/blob/main/dinov3/layers/attention.py)

还应抽样核查“参考是否来自正确结构”，测试保持标签有效的轻微光照/位移变化。GT 重叠说明相关性，干预说明模型响应，都不单独构成完整正确性证明。若增加独立分割分支，需分别说明解释覆盖哪条分支及其最终贡献。

尤其要避免循环论证：模型本来按距离评分，替换后距离下降只是预期响应，不能单独当作解释贡献。还需比较正确结构参照与无约束参照，条件允许时加入距离相近但结构错误的参照对照，检查依据是否具有结构有效性。参考语义正确、评分可追溯和任务改善分别需要证据。

### 5.3 一张图的完整数据流

```text
原图 RGB [1070,1404,3] + 原mask
→ 原mask非零ID合并为1；正常图生成全零GT
→ 训练时同步水平翻转
→ 等比例缩为512×390，上下各补61；标签padding=255
→ 图像一次x/255与均值/标准差归一化，转[B,3,512,512]
→ MiT-B0四尺度编码 → SegFormer解码 → [B,2,128,128] logits
  ├─ 训练：上采样至512 → CE＋0.5×前景Soft Dice → 反向传播
  └─ 评价：logits到512 → 裁padding → 原H/W → softmax → p≥0.5
                                      与原尺寸0/1 GT计分
```

RGB 用 Pillow BILINEAR，标签用 NEAREST。processor 关闭重复 resize/reduce_labels；标签不归一化。先补255再做 >0 会把 padding 变成缺陷；先阈值化再训练会破坏正常梯度路径。

### 5.4 结构要掌握到什么程度

输入 512 时，MiT-B0 的四尺度为 `[B,32,128,128]`、`[B,64,64,64]`、`[B,160,32,32]`、`[B,256,16,16]`。解码头将各尺度投影到256通道并对齐至128网格，拼接/融合后输出两个类别通道。

先理解 overlapping patch embedding、层级下采样、空间缩减 attention、Mix-FFN、四尺度融合。能把“空间尺寸、通道、token 数”分开，再按需读数学推导。SegFormer 是整体分割方案，MiT 是编码器，ViT 是相关架构，不是完全同义词。

**权重细节：192/192 编码器张量匹配。**原分类 checkpoint 共194项，另2项属于未使用的 ImageNet 分类头；不是少加载2项编码器。整个分割 decode_head 新建。部分旧实验卡的“192/194”简写按此理解，原记录不修改。

### 5.5 训练和评价的关键问题

- CE 接收 logits，忽略255，在有效像素上归约；不先 softmax 再喂当前 cross_entropy 接口。
- 当前 Dice 只对 GT 有缺陷的图计算。正常图仍通过 CE 惩罚误报；全正常 batch 不等于没有梯度。
- AdamW 更新权重；AMP/scaler 处理低精度梯度；scheduler 控制学习率。能解释各自作用，暂不背所有超参数。
- 训练 AMP 与原图 FP32 评价分开；恢复 logits 后再 softmax/阈值，原 GT 不由512标签放大生成。
- 评价技术复核没有重新挑 epoch 或阈值，不能说 test 只前向一次；预测一致不等于恢复训练轨迹必然完全一致。
