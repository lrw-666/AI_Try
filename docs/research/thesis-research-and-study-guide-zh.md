## 1. 当前研究方向：哪些已经收敛

### 1.1 题目、对象与总问题

**题目采用导师建议：《PCB外观缺陷检测方法研究》。**

具体任务是：以 PCB 板级 RGB 外观图像为输入，利用已有像素标注进行背景/缺陷二值分割，输出原图尺度的缺陷位置与范围。目前从 VisA PCB1、官方 2-class high-shot 的派生协议起步。

建议总问题：

> 如何将预训练视觉表征有效适配于 PCB 外观缺陷检测，提高局部缺陷的分割与定位精度，并提供与模型实际决策一致、可验证的判别依据？

| 层次 | 当前口径 |
| --- | --- |
| 应用领域 | 工业视觉检测中的 PCB 外观缺陷检测 |
| 具体任务 | 有真实像素标注的监督二值分割；当前不输出缺陷类别 |
| 精度研究 | 减少缺陷漏检、控制正常区域误报，查明改动改善了哪些错误 |
| 解释研究 | 检查哪些区域或正常参照实际参与判别，以及依据是否可靠 |
| 技术入口 | 预训练特征迁移与任务适配；DINOv3 是候选，不预设必胜 |
| 结论边界 | 不涉及电气功能、内部焊点或制造原因诊断；公开数据结果不等于产线验收 |
| 实施条件 | 在职非全日制、Python/PyTorch 优先、难度适中；算力与时间列入可行性 |

**有限算力不放入核心研究问题。**只有明确研究精度与计算代价取舍，并完成对应实验时，效率才成为研究内容。没有小论文发表指标是已有个人记录，不替代学院最新正式要求。

### 1.2 导师反馈怎样理解

导师已支持工业视觉检测，建议上述题目，并提出“检测精度提升、可解释性”“最好有两个以上工作”。按这一已明确的方向持续研究；候选机制由文献、诊断与实验收敛，不要求先安排新的导师讨论。方法有效性、新颖性和工作量仍由实质研究说明。

目前可按两项相关工作组织：**工作一研究特征适配，工作二研究可核验判别证据。**两项可以共用数据与模型，但要分别有问题、方法、比较和结论。两个模型、两个章节或多个工程阶段不自动等于两项贡献。

### 1.3 现实与文献依据

工业缺陷往往是正常产品中的局部差异。通用预训练提供可复用信息，但不保证这些信息能直接支持当前缺陷定位；适配、空间细节和监督条件都可能影响效果。相关研究已充分存在，本文不把“使用预训练模型”写成空白。

另一方面，分数较高仍可能依赖不稳健线索；核验判别依据有助于发现问题。**缺陷掩码回答哪里，模型解释回答依据什么，工艺诊断回答制造原因**，三者分开。直接相关文献及用途见[第 7 节](#s7)。

### 1.4 一分钟口述稿

> 我研究 PCB 外观缺陷的像素级定位，重点关注缺陷漏检和正常区域误报。项目已完成 VisA PCB1 上的 SegFormer-B0 监督分割基线。后续先建立冻结 DINOv3 加简单分割头的独立对照，再围绕明确错误开展特征适配，并研究与实际评分相联系的正常参照证据。两项工作的具体机制仍需查新和实验验证，目前不预设 DINO 更好，也不声称已达到产线标准。

## 2. SegFormer、DINO 与两项工作的关系

| 内容 | 当前状态 | 在论文中的作用 |
| --- | --- | --- |
| SegFormer-B0 | 已完成并有验收记录 | 可信基线、统一实验平台、错误诊断入口；也可能承载后续改进 |
| 冻结 DINOv3-S/16＋简单头 | 待实施 | 独立迁移对照，检验固定表征中有多少信息能用于 PCB 定位 |
| 工作一的适配 | 设计草稿 | 针对具体错误改变特征利用方式，检验精度收益及代价 |
| 工作二的证据判别 | 设计草稿 | 将可追溯正常参照与实际评分联系起来，并验证依据 |
| 融合、预测集成、蒸馏 | 条件候选 | 出现互补证据且有必要时再讨论，不预设为必做 |

现有 SegFormer 工程包括数据、几何、训练、选模、原图评价与图表，公共部分可继续使用。它本身不自动构成方法创新，也不需要因为要研究 DINO 就废弃。后续新实验应单独归档，保留原基线作比较。

```text
共同数据与评价协议
  ├─ SegFormer-B0：已完成的独立基线
  └─ 冻结 DINOv3＋简单头：拟开展的独立对照
          ↓ 结合 train/val 诊断与文献
     工作一：一项局部细节适配
     工作二：一种正常参照证据判别
          ↓
     对照、消融、解释验证、重复与独立数据 → 适用边界
```

该图表示研究依赖，不表示已决定把两种骨干融合。若 DINO 不适合，保留真实结果，并与导师讨论采用更有证据的载体；不自动取消原定对照，也不靠模型更新保证贡献。

## 3. 两项研究设计表初稿

### 3.1 初稿的定位

为方便开题，下面各给一个**主要候选**，避免只罗列菜单。选取它们是基于已知定位错误和相关研究形成的建议，不代表诊断已证明原因。实现前先做 train/val 诊断与最近工作对照；不满足条件时需调整，不包装成已成立创新。

### 3.2 完整设计表

| 设计项 | 工作一：局部细节引导的预训练特征适配 | 工作二：结构约束的正常参照判别 |
| --- | --- | --- |
| 研究问题 | 引入原图局部细节，能否改善冻结表征的缺陷覆盖，并控制正常纹理误报？ | 正常参照能否直接参与缺陷评分，形成可追溯、可干预核查的依据？ |
| 当前证据 | 已有定位漏检与正常误报；数据审计也发现少量极小 GT 域缩放后消失。但尚未证明它们是主要成因 | 正常结构误报提示需要检查判别依据；当前没有解释方法或正常参照实验 |
| 核心假设 | 一部分错误与局部信息表达/利用不足有关；从输入补充细节可能有效 | 同结构参照比无约束全图检索更少错配；实际差异证据应影响评分 |
| 输入与输出 | RGB 图像→原图缺陷概率及二值掩码 | 待测图＋仅由训练正常图构建的参照库→缺陷得分、掩码、实际参照与来源坐标 |
| 主候选机制 | 冻结 DINO 提取空间特征；从输入 RGB 提取较高分辨率局部特征，经投影与残差适配接入统一分割头 | 特征提取器固定后建立正常块库；在可靠对齐的结构位置内检索正常块，用实际距离残差形成得分 |
| 拟训练内容 | 局部分支、适配层、二类头；骨干先冻结，保持与简单头对照的定义清楚 | 可使用训练正常/异常及 mask 拟合简单单调评分映射；参照选择、阈值与约束不接触 test |
| 已有技术基础 | 冻结特征、局部/语义融合与轻量适配都已有研究，需与 S³DNet 等核差异 | 正常记忆库与最近邻已有 PatchCore；参考差异已有 CADNet；检索本身不是新颖性 |
| 主要基线 | 原 SegFormer；同 DINO＋简单头；常规卷积头/简单融合 | 普通分割头；普通全局正常块检索；结构约束检索 |
| 必要控制 | 输入尺度、训练/验证协议、预处理与评价固定；检查收益是否仅来自容量或更大输入 | 同一特征、库规模和划分；移除位置约束、替换约束；核查配准和结构匹配 |
| 主要评价 | 原图 IoU、Dice、像素召回、逐图表现、正常误报；按预定义尺度分层；时间/显存作为代价 | 保留定位与误报指标；补充参考匹配正确性、得分干预响应、证据稳定性与伪影控制 |
| 失败条件 | train/val 诊断不支持问题；收益不稳定；与简单增容无区别；召回提升伴随不可接受的误报 | 配准不可靠、常匹配错误结构；关键证据干预与随机干预无差别；依据无法覆盖最终评分 |
| 预期交付 | 方法图、错误分组、对照/消融、收益与无收益条件 | 实际评分路径、参照可视化、可靠性实验及局限 |
| 当前状态 | 未实施、未证明有效，方法新颖性待核 | 未实施；参照数据条件与评价可行性待核 |

### 3.3 机制怎样讲清

工作一的草稿流程：

```text
RGB ──→ 冻结 DINO 空间特征 ──→ 对齐/投影 ─┐
  └──→ 局部卷积分支（较细网格）────────────┤
                            残差适配/融合 → 二类头 → 原图预测
```

增加局部分支只是候选机制；不会凭空恢复输入已丢失的内容，也可能放大正常纹理误报。必须与简单融合、普通增容、尺度调整比较。若与已有方案没有实质差异，需要重新收窄方法设计。

工作二可用如下形式说明评分草稿：

```text
固定特征 z_p → 从训练正常库 M(p) 检索 → 距离 d_p → 单调映射 → 缺陷得分
```

例如 d_p 为待测块与允许参照集合中最近特征的距离；映射随距离单调增加。它便于追溯评分真正采用的参照，但不能因此宣称输出已是校准概率或解释了整套制造过程。映射和阈值由 train/val 确定。

**关键数据条件：VisA 没有每张待测图逐一配对的“黄金正常板”。**不能假设已有完美对应参考。参照库只能来自训练正常图；先检验 PCB1 姿态、板型与配准是否支持位置约束。若不支持，位置约束候选不成立，应讨论改变机制或数据条件，不暗中增加人工标注任务。

### 3.4 两项工作如何分别成立

工作一回答“怎样改善特征”；工作二回答“怎样构造与评分绑定的依据”。可考虑以下 2×2 对照：

| 特征 | 普通分割头 | 参照判别 |
| --- | --- | --- |
| 原冻结特征 | DINO 简单头基线 | 先独立验证工作二 |
| 工作一适配特征 | 独立验证工作一 | 检验两者结合及相互影响 |

各条件下固定特征后再建对应训练正常库，避免混用特征空间。该表能检查机制独立性；创新性与工作量还需由方法差异和实验结果说明。

### 3.5 解释验证的最小草案

解释对象先限定为某个区域的实际缺陷得分。拟比较：高证据区域用匹配正常块替换、等面积随机区域替换、正常区域替换；再做正常→正常替换控制拼接伪影。观察评分和预测变化，辅以适用的随机化检查。

还应抽样核查“参考是否来自正确结构”，测试保持标签有效的轻微光照/位移变化。GT 重叠说明相关性，干预说明模型响应，都不单独构成完整正确性证明。若增加独立分割分支，需分别说明解释覆盖哪条分支及其最终贡献。

尤其要避免循环论证：模型本来按距离评分，替换后距离下降只是预期响应，不能单独当作解释贡献。还需比较正确结构参照与无约束参照，条件允许时加入距离相近但结构错误的参照对照，检查依据是否具有结构有效性。参考语义正确、评分可追溯和任务改善分别需要证据。

### 4.2 四条必须会解释的结果边界

1. test 的 049、057 预测为空；077 虽预测 351 像素，但全为 FP。共 3 张异常没有命中真实缺陷；报警与正确定位是不同问题。
2. recall=0.739 是缺陷像素召回，不能换算为坏板检出率；32/402 是存在任意 FP 的正常图数，尚无板级判废规则。
3. global 先累计 TP/FP/FN，macro 对异常图等权；差值不单独证明小缺陷更差。正常图空 GT 且空预测的逐图 IoU/Dice 为 NA，误报另报。
4. 单类别、单 seed、40 张异常 test，没有工业现场或稳定推理延迟证据。评价总耗时包含读图/保存，不能当模型延迟。

公式：IoU=TP/(TP+FP+FN)，Dice=2TP/(2TP+FP+FN)，precision=TP/(TP+FP)，recall=TP/(TP+FN)。当前若全部预测正常，像素 accuracy 仍约 99.95%，缺陷 recall 却为 0。

### 4.3 已有的细节证据怎样用

[数据审计](../../work/SegFormer/reports/data_audit/summary.md)对 PCB1 全部 100 张异常图进行了 GT 几何检查：328 个原始连通域中，19 个在 512 标签采样后消失，涉及 12 图，原面积合计 39 像素（单域 1—8 像素）；没有整张异常 GT 变空。

这说明缩放确实可能丢失极小标注区域，但这些是几何域，不等同专家定义的缺陷实例，也不能解释当前所有漏检。该全数据历史审计已经接触 test；后续方法诊断回到 train/val，并披露接触记录。

## 5. 基线学习路线：按产出掌握，不按脚本数量阅读

### 5.3 一张图的完整数据流

```text
原图 RGB [1070,1404,3] + 原mask
→ 原mask非零ID合并为1；正常图生成全零GT
→ 训练时同步水平翻转
→ 等比例缩为512×390，上下各补61；标签padding=255
→ 图像一次x/255与均值/标准差归一化，转[B,3,512,512]
→ MiT-B0四尺度编码 → SegFormer解码 → [B,2,128,128] logits
  ├─ 训练：上采样至512 → CE＋0.5×前景Soft Dice → 反向传播
  └─ 评价：logits到512 → 裁padding → 原H/W → softmax → p≥0.5
                                      与原尺寸0/1 GT计分
```

RGB 用 Pillow BILINEAR，标签用 NEAREST。processor 关闭重复 resize/reduce_labels；标签不归一化。先补255再做 >0 会把 padding 变成缺陷；先阈值化再训练会破坏正常梯度路径。

### 5.4 结构要掌握到什么程度

输入 512 时，MiT-B0 的四尺度为 `[B,32,128,128]`、`[B,64,64,64]`、`[B,160,32,32]`、`[B,256,16,16]`。解码头将各尺度投影到256通道并对齐至128网格，拼接/融合后输出两个类别通道。

先理解 overlapping patch embedding、层级下采样、空间缩减 attention、Mix-FFN、四尺度融合。能把“空间尺寸、通道、token 数”分开，再按需读数学推导。SegFormer 是整体分割方案，MiT 是编码器，ViT 是相关架构，不是完全同义词。

**权重细节：192/192 编码器张量匹配。**原分类 checkpoint 共194项，另2项属于未使用的 ImageNet 分类头；不是少加载2项编码器。整个分割 decode_head 新建。部分旧实验卡的“192/194”简写按此理解，原记录不修改。

### 5.5 训练和评价的关键问题

- CE 接收 logits，忽略255，在有效像素上归约；不先 softmax 再喂当前 cross_entropy 接口。
- 当前 Dice 只对 GT 有缺陷的图计算。正常图仍通过 CE 惩罚误报；全正常 batch 不等于没有梯度。
- AdamW 更新权重；AMP/scaler 处理低精度梯度；scheduler 控制学习率。能解释各自作用，暂不背所有超参数。
- 训练 AMP 与原图 FP32 评价分开；恢复 logits 后再 softmax/阈值，原 GT 不由512标签放大生成。
- 评价技术复核没有重新挑 epoch 或阈值，不能说 test 只前向一次；预测一致不等于恢复训练轨迹必然完全一致。

### 9.3 关键页面具体怎样组织

**第2页：研究背景与意义。**只解释本课题需要的背景：板级正常结构复杂，局部异常需要定位，漏检和误报都应评价。用真实PCB图帮助评委理解对象；不增加缺少来源的市场规模、损失金额或“已达到工业标准”表述。

**第3页：国内外现状。**可用三行组织：

| 路线 | 代表工作 | 对本研究的启发及边界 |
| --- | --- | --- |
| 工业监督分割/迁移 | SPD（ECCV2022）、SuperSimpleNet（ICPR2024） | 已有任务与特征适配基础；监督协议要区分 |
| 局部细节与参考差异 | CADNet（2025）、S³DNet（2026，钢带分割） | 分别提供PCB参考差异、相邻工业局部适配先例；不能当作同协议成绩 |
| 判别依据与可靠性 | Kauffmann等（NMI2025）/PatchCore（CVPR2022） | 需要检查依据；正常记忆库与检索已有先例 |

正文只选3—4篇讲清楚，其他放备用。结尾归纳“特征适配”和“判别依据”两个切入点，不宣称领域空白。国内外可按研究路线共同分析，不必各列一页人名。

**第5页：总体路线。**SegFormer标为已有基线；DINO与两项方法标为拟开展。普通头和参照头可以共享特征，对照关系与最终融合分开。讲清“研究内容”与“执行步骤”不同，不把两个模型当两个创新点。

**第6页：工作一。**图上突出拟增加的局部细节适配，旁边只留三点：要缓解哪种错误、增加什么信息、怎样验证作用。页脚写“拟研究方案，效果待验证”。现阶段可用设计图，不能画不存在的提升曲线。与简单头、普通增容/融合及尺度控制的比较在第9页接续。

**第8页：前期基础。**仅展示已核实的SegFormer结果：test全局IoU 0.6833、像素recall 0.7390、异常图macro IoU 0.5249，注明PCB1、单seed。正常误报32/402可口述或放备用，准确称为“有任意FP像素的正常图”。以一个真实案例说明已有实现与仍有困难，避免展示13阶段流水账。可从第4.4节取图；案例须注明属于已查看数据。

**第9页：实验与预期贡献。**精度方向说明同协议比较、必要消融、逐图/正常误报；依据方向说明正确结构参照、等面积随机干预、伪影控制和稳定性。角落说明train/val开发、冻结后评价及既有test接触。预期贡献写“拟验证的机制/依据方法及适用边界”，不写“两项创新已实现”。

**第10页：计划与成果。**用阶段顺序表示后续安排；最终毕业节点尚未核实时用阶段而非编造日期。预期成果包括论文、方法实验及可复核记录；不预设GUI、部署、发表或固定涨分。最后口述结束语即可，无需额外致谢页。
