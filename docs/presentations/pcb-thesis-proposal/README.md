## 与研究计划的对应

SegFormer承担已有基线与错误诊断平台的作用。冻结DINOv3加简单头、局部细节适配与正常参照判别均标为拟开展，效果与具体机制差异仍需验证。工作二的正常参照库只使用训练正常图，训练掩码用于拟合评分映射，验证集确定工作点；可靠结构对齐是使用该约束的前提。

基线指标直接引用`work/SegFormer/reports/pcb1_b0_v2_seed42/results.md`：原图全局前景IoU 0.6833、缺陷像素Recall 0.7390、异常图Macro IoU 0.5249。明确披露单类别、单seed及已经查看测试结果的条件。图中ROI仅用于展示，指标按原图评价。没有将像素误报换算为产线误剔率，也没有宣称已达到工业验收标准。
