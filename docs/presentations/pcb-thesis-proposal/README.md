## 研究内容与版本说明

工作一关注缺陷覆盖和正常误报，预训练表征适配是候选入口；工作二关注模型依据什么判断，以及解释的忠实性、参照匹配、稳定性和覆盖范围。可解释性工作另报检测效果与成本，不以IoU必须提升为成立条件。SegFormer为已有基线，DINO与两项具体方法仍拟开展。

DINOSaur v2已有空间正常库、邻域距离与像素定位评价，已补入研究现状及近邻比较。正常参照图展示需绑定实际评分，位置邻域不等于结构语义，来源patch特征还包含图像上下文。单调距离映射作为基础评分或工作点处理，不单独声称增加定位能力。细节及来源保留在各页备注，正文以研究问题和验证逻辑为主。

**控时：** 正文第2页｜本页30秒｜累计0:10—0:40｜正文目标7分钟（含切页和停顿）

**演讲词：** PCB外观图像包含元件和连接结构，缺陷往往只占局部区域，正常纹理也可能引起误报。实际检测既需要找出缺陷的位置和范围，也需要核查模型采用了什么依据。因此，本课题从公开PCB图像出发，研究怎样减少漏检、控制正常误报，并为检测结果提供可以验证的判别说明。

### 第7页：工作二：可解释性

**控时：** 正文第7页｜本页55秒｜累计3:35—4:30｜正文目标7分钟（含切页和停顿）

**指图与控时提示（不朗读）：** 正文第7页；累计3:35—4:30。先点明解释对象，再沿训练正常库→候选筛选→近邻距离→实际得分指图。位置约束标为待验证；val只确定工作点，不将严格单调换刻度当新增定位机制。来源patch token含整图上下文，保留整图并标记patch；来源裁剪本身不是完整像素归因。CADNet需要参考图，作为条件不同的相关研究保留于来源。结束检查点约4:30。
