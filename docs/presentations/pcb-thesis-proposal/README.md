### 第2页：研究背景与意义

**控时：** 正文第2页｜本页30秒｜累计0:10—0:40｜正文目标7分钟（含切页和停顿）

**演讲词：** PCB外观图像包含元件和连接结构，缺陷往往只占局部区域，正常结构也可能产生相似响应。因此，本课题既关注缺陷能否准确定位，也关注正常区域是否误报，并核查模型判别采用的证据。研究先在公开数据上验证，产线应用还需要实际成像和验收条件支持。

**指图与控时提示（不朗读）：** 指左侧板级图，再指右侧三个目标；不展开产线部署细节。

**演讲词：** 相关研究已经提供三方面基础。第一，监督迁移和冻结特征适配说明，预训练表征能否用于缺陷定位，需要下游检验。第二，国内外已有PCB参考差异和工业细节适配方法，说明我的两项候选机制都有相近研究，必须核查差异。第三，工业模型可能利用不稳健线索，仅展示热图不足以验证判别依据。因此，本课题的切入点是任务适配和依据核验，不把换用新模型当作创新。

### 第6页：工作一：局部细节引导的特征适配

**控时：** 正文第6页｜本页55秒｜累计2:40—3:35｜正文目标7分钟（含切页和停顿）

**演讲词：** 工作一拟研究局部细节引导的特征适配。假设一部分定位错误与局部信息表达或利用不足有关。具体方案是冻结DINO骨干，同时从输入提取较细网格的卷积特征，经投影和残差适配后，共同支持二类分割。训练局部分支、适配层与分割头。关键比较包括简单头、普通增容和简单融合，并控制输入尺度，排查收益是否仅来自容量或分辨率变化。局部分支也可能增加正常纹理误报，所以需要同时报告缺陷覆盖与误报。机制差异和实际效果仍需验证。

## 与研究计划的对应
