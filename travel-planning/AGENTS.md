# Travel Planning Agent Context

This folder is for reusable travel planning records, destination research, itinerary drafts, booking checklists, and final travel documents.

## Language and Naming

- Use English names for folders and files unless the user explicitly requests otherwise.
- Markdown records in this folder should be written in English by default, following the workspace-wide rule.
- User-facing travel deliverables may be written in Chinese when the request is in Chinese or when the user clearly benefits from a Chinese itinerary.
